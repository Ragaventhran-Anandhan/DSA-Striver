Problem 293: Inorder Traversaleasy

Question Statement

Left, Root, Right.

Input: root=[1,null,2,3]
Output:
[1,3,2]

Brute force

Collect nodes in a list by repeated search.

Optimized idea

Recursive Left, Root, Right.

Why it works

Visiting each node once gives O(n); for a BST the output is sorted.

Java implementation

public static List<Integer> inorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    go(root, res);
    return res;
}

private static void go(TreeNode n, List<Integer> res) {
    if (n == null) return;
    go(n.left, res);
    res.add(n.val);
    go(n.right, res);
}

Explanation

  1. Recurse left
  2. Add root value
  3. Recurse right

Height of the tree.

Output:
3

Brute force

BFS counting levels.

Optimized idea

Recursion: 1 + max(height of left, height of right).

Why it works

The height of a node depends only on its children.

public static int maxDepth(TreeNode root) {

}

Problem 297: Check for Balanced Binary Treeeasy

Question Statement

Height difference <= 1 for all nodes.

Input: root=[3,9,20,null,null,15,7]
Output:
true

Brute force

Compute heights separately at every node, O(n^2).

Optimized idea

Return height and -1 for unbalanced in one traversal.

Why it works

A -1 propagates immediately, avoiding recomputation.

Java implementation

public static boolean isBalanced(TreeNode root) {
    return height(root) != -1;
}

private static int height(TreeNode n) {
    if (n == null) return 0;
    int l = height(n.left), r = height(n.right);
    if (l == -1 || r == -1 || Math.abs(l - r) > 1) return -1;
    return 1 + Math.max(l, r);
}

Explanation

  1. Height of left and right
  2. If either is -1 or difference > 1 return -1
  3. Else return 1 + max

Problem 299: Search in a BSTeasy

Question Statement

Find node with value.

Input: root=[4,2,7,1,3], val=2
Output:
[2,1,3]

Brute force

Traverse the whole tree.

Optimized idea

Use the BST property to go left or right.

Why it works

Each step discards one subtree, giving O(h).

Java implementation

public static TreeNode searchBST(TreeNode root, int val) {
    while (root != null && root.val != val) root = val < root.val ? root.left : root.right;
    return root;
}

Explanation

  1. While node != null
  2. If equal return
  3. Go left if val is smaller else right

Problem 301: Ceil in BSTeasy

Question Statement

Smallest value >= key.

Input: root=[10,5,13,2,6,11,14], key=8
Output:
10

Brute force

Inorder list then search.

Optimized idea

Walk down remembering the best candidate >= key.

Why it works

Moving left when value >= key tightens the candidate.

Java implementation

public static int ceilBST(TreeNode root, int key) {
    int ceil = -1;
    while (root != null) {
        if (root.val == key) return key;
        if (root.val > key) { ceil = root.val; root = root.left; }
        else root = root.right;
    }
    return ceil;
}

Explanation

  1. ceil = -1
  2. If val == key return it
  3. If val > key record ceil and go left
  4. Else go right

Problem 303: Level Order Traversalmedium

Question Statement

BFS level by level.

Input: root=[3,9,20,null,null,15,7]
Output:
[[3],[9,20],[15,7]]

Brute force

Compute depth of each node and group.

Optimized idea

BFS with a queue, processing one level at a time.

Why it works

Queue size at the start of a round equals the level size.

Java implementation

public static List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    while (!q.isEmpty()) {
        int sz = q.size();
        List<Integer> lvl = new ArrayList<>();
        for (int i = 0; i < sz; i++) {
            TreeNode n = q.poll();
            lvl.add(n.val);
            if (n.left != null) q.add(n.left);
            if (n.right != null) q.add(n.right);
        }
        res.add(lvl);
    }
    return res;
}

Explanation

  1. Queue the root
  2. For each level take size nodes
  3. Collect values and enqueue children

Problem 304: Iterative Preorder Traversalmedium

Question Statement

Using a stack.

Input: root=[1,2,3]
Output:
[1,2,3]

Brute force

Recursive preorder.

Optimized idea

Stack: push right then left.

Why it works

Left is popped first so it is visited before right.

Java implementation

public static List<Integer> preorderIterative(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> st = new ArrayDeque<>();
    st.push(root);
    while (!st.isEmpty()) {
        TreeNode n = st.pop();
        res.add(n.val);
        if (n.right != null) st.push(n.right);
        if (n.left != null) st.push(n.left);
    }
    return res;
}

Explanation

  1. Push root
  2. Pop, record
  3. Push right then left

Problem 305: Iterative Inorder Traversalmedium

Question Statement

Using a stack.

Input: root=[1,2,3]
Output:
[2,1,3]

Brute force

Recursive inorder.

Optimized idea

Stack: go left as far as possible then visit and go right.

Why it works

The stack simulates the recursion path.

Java implementation

public static List<Integer> inorderIterative(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !st.isEmpty()) {
        while (cur != null) { st.push(cur); cur = cur.left; }
        cur = st.pop();
        res.add(cur.val);
        cur = cur.right;
    }
    return res;
}

Explanation

  1. Push the left chain
  2. Pop and record
  3. Move to the right child

Problem 306: Iterative Postorder (2 Stacks)medium

Question Statement

Using two stacks.

Input: root=[1,2,3]
Output:
[2,3,1]

Brute force

Recursive postorder.

Optimized idea

Two stacks: reverse of Root, Right, Left.

Why it works

Postorder is the reverse of a modified preorder.

Java implementation

public static List<Integer> postorderTwoStacks(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> s1 = new ArrayDeque<>(), s2 = new ArrayDeque<>();
    s1.push(root);
    while (!s1.isEmpty()) {
        TreeNode n = s1.pop();
        s2.push(n);
        if (n.left != null) s1.push(n.left);
        if (n.right != null) s1.push(n.right);
    }
    while (!s2.isEmpty()) res.add(s2.pop().val);
    return res;
}

Explanation

  1. Pop from stack 1 and push to stack 2
  2. Push left then right to stack 1
  3. Stack 2 pops in postorder

Problem 307: Iterative Postorder (1 Stack)medium

Question Statement

Using one stack.

Input: root=[1,2,3]
Output:
[2,3,1]

Brute force

Two stacks.

Optimized idea

One stack with a last-visited pointer.

Why it works

A node is processed only after its right child has been visited.

Java implementation

public static List<Integer> postorderOneStack(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root, last = null;
    while (cur != null || !st.isEmpty()) {
        if (cur != null) { st.push(cur); cur = cur.left; }
        else {
            TreeNode top = st.peek();
            if (top.right != null && last != top.right) cur = top.right;
            else { res.add(top.val); last = st.pop(); }
        }
    }
    return res;
}

Explanation

  1. Go left pushing nodes
  2. Peek the top
  3. If it has an unvisited right child go there
  4. Else pop and record

Problem 308: Preorder, Inorder and Postorder in One Traversalmedium

Question Statement

Single traversal for all three.

Input: root=[1,2,3]
Output:
[[1,2,3],[2,1,3],[2,3,1]]

Brute force

Three separate traversals.

Optimized idea

One stack with a visit-count state per node.

Why it works

State 1 = preorder, 2 = inorder, 3 = postorder; each node is touched three times.

Java implementation

public static List<List<Integer>> allTraversals(TreeNode root) {
    List<Integer> pre = new ArrayList<>(), in = new ArrayList<>(), post = new ArrayList<>();
    if (root == null) return Arrays.asList(pre, in, post);
    Deque<Object[]> st = new ArrayDeque<>();
    st.push(new Object[]{root, 1});
    while (!st.isEmpty()) {
        Object[] top = st.pop();
        TreeNode n = (TreeNode) top[0];
        int s = (int) top[1];
        if (s == 1) { pre.add(n.val); st.push(new Object[]{n, 2}); if (n.left != null) st.push(new Object[]{n.left, 1}); }
        else if (s == 2) { in.add(n.val); st.push(new Object[]{n, 3}); if (n.right != null) st.push(new Object[]{n.right, 1}); }
        else post.add(n.val);
    }
    return Arrays.asList(pre, in, post);
}

Explanation

  1. Push (node, 1)
  2. State 1: add to pre and push left
  3. State 2: add to in and push right
  4. State 3: add to post

Problem 309: Diameter of Binary Treemedium

Question Statement

Longest path between any two nodes (edges).

Input: root=[1,2,3,4,5]
Output:
3

Brute force

Compute height of both sides at every node, O(n^2).

Optimized idea

Single DFS updating a global max of left + right heights.

Why it works

The longest path through a node is leftHeight + rightHeight.

Java implementation

public static int diameterOfBinaryTree(TreeNode root) {
    int[] best = {0};
    height(root, best);
    return best[0];
}

private static int height(TreeNode n, int[] best) {
    if (n == null) return 0;
    int l = height(n.left, best), r = height(n.right, best);
    best[0] = Math.max(best[0], l + r);
    return 1 + Math.max(l, r);
}

Explanation

  1. Return height
  2. At each node update diameter
  3. Return the diameter

Problem 310: Zigzag Level Order Traversalmedium

Question Statement

Alternate direction per level.

Input: root=[3,9,20,null,null,15,7]
Output:
[[3],[20,9],[15,7]]

Brute force

Level order then reverse alternate levels.

Optimized idea

BFS with a direction flag inserting at the front or back.

Why it works

Placing items in the right index avoids a reverse step.

Java implementation

public static List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.add(root);
    boolean ltr = true;
    while (!q.isEmpty()) {
        int sz = q.size();
        LinkedList<Integer> lvl = new LinkedList<>();
        for (int i = 0; i < sz; i++) {
            TreeNode n = q.poll();
            if (ltr) lvl.addLast(n.val); else lvl.addFirst(n.val);
            if (n.left != null) q.add(n.left);
            if (n.right != null) q.add(n.right);
        }
        res.add(lvl);
        ltr = !ltr;
    }
    return res;
}

Explanation

  1. BFS by level
  2. Left to right: add at the end
  3. Right to left: add at the front
  4. Flip the flag

Problem 311: Boundary Traversalmedium

Question Statement

Anticlockwise boundary.

Input: root=[1,2,3,4,5,6,7]
Output:
[1,2,4,5,6,7,3]

Brute force

Traverse and pick boundary nodes by checking each.

Optimized idea

Left boundary, leaves, right boundary (reversed).

Why it works

The boundary is exactly these three parts without duplicates.

Java implementation

public static List<Integer> boundaryTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    if (!isLeaf(root)) res.add(root.val);
    for (TreeNode n = root.left; n != null; ) {
        if (!isLeaf(n)) res.add(n.val);
        n = n.left != null ? n.left : n.right;
    }
    leaves(root, res);
    List<Integer> right = new ArrayList<>();
    for (TreeNode n = root.right; n != null; ) {
        if (!isLeaf(n)) right.add(n.val);
        n = n.right != null ? n.right : n.left;
    }
    Collections.reverse(right);
    res.addAll(right);
    return res;
}

private static boolean isLeaf(TreeNode n) { return n.left == null && n.right == null; }

private static void leaves(TreeNode n, List<Integer> res) {
    if (n == null) return;
    if (isLeaf(n)) res.add(n.val);
    leaves(n.left, res);
    leaves(n.right, res);
}

Explanation

  1. Add root if not a leaf
  2. Walk left boundary skipping leaves
  3. Add all leaves
  4. Walk right boundary skipping leaves and reverse

Problem 312: Vertical Order Traversalmedium

Question Statement

Column by column.

Input: root=[3,9,20,null,null,15,7]
Output:
[[9],[3,15],[20],[7]]

Brute force

Compute coordinates and sort everything.

Optimized idea

BFS tracking (column, row) in a nested TreeMap.

Why it works

Sorting by column, row and then value matches the required order.

Java implementation

public static List<List<Integer>> verticalTraversal(TreeNode root) {
    TreeMap<Integer, TreeMap<Integer, PriorityQueue<Integer>>> m = new TreeMap<>();
    Queue<Object[]> q = new LinkedList<>();
    q.add(new Object[]{root, 0, 0});
    while (!q.isEmpty()) {
        Object[] o = q.poll();
        TreeNode n = (TreeNode) o[0];
        if (n == null) continue;
        int c = (int) o[1], r = (int) o[2];
        m.computeIfAbsent(c, k -> new TreeMap<>()).computeIfAbsent(r, k -> new PriorityQueue<>()).add(n.val);
        q.add(new Object[]{n.left, c - 1, r + 1});
        q.add(new Object[]{n.right, c + 1, r + 1});
    }
    List<List<Integer>> res = new ArrayList<>();
    for (TreeMap<Integer, PriorityQueue<Integer>> rows : m.values()) {
        List<Integer> col = new ArrayList<>();
        for (PriorityQueue<Integer> pq : rows.values()) while (!pq.isEmpty()) col.add(pq.poll());
        res.add(col);
    }
    return res;
}

Explanation

  1. BFS storing (node, col, row)
  2. map[col][row] holds a priority queue
  3. Output columns in order

Problem 313: Top View of Binary Treemedium

Question Statement

Nodes visible from top.

Input: root=[1,2,3,4,5,6,7]
Output:
[4,2,1,3,7]

Brute force

Check each node for blocking nodes above.

Optimized idea

BFS storing the first node per column.

Why it works

Level order reaches the topmost node of each column first.

Java implementation

public static List<Integer> topView(TreeNode root) {
    TreeMap<Integer, Integer> m = new TreeMap<>();
    Queue<Object[]> q = new LinkedList<>();
    if (root != null) q.add(new Object[]{root, 0});
    while (!q.isEmpty()) {
        Object[] o = q.poll();
        TreeNode n = (TreeNode) o[0];
        int c = (int) o[1];
        m.putIfAbsent(c, n.val);
        if (n.left != null) q.add(new Object[]{n.left, c - 1});
        if (n.right != null) q.add(new Object[]{n.right, c + 1});
    }
    return new ArrayList<>(m.values());
}

Explanation

  1. Queue (node, column)
  2. putIfAbsent per column
  3. Output columns from left to right

Problem 315: Right/Left View of Binary Treemedium

Question Statement

Nodes visible from right.

Input: root=[1,2,3,null,5,null,4]
Output:
[1,3,4]

Brute force

Level order then take the last of each level.

Optimized idea

DFS visiting right first, recording the first node per depth.

Why it works

The first node seen at each depth is the rightmost one.

Java implementation

public static List<Integer> rightView(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    dfs(root, 0, res);
    return res;
}

private static void dfs(TreeNode n, int d, List<Integer> res) {
    if (n == null) return;
    if (d == res.size()) res.add(n.val);
    dfs(n.right, d + 1, res);
    dfs(n.left, d + 1, res);
}

Explanation

  1. Recurse with depth
  2. If depth == result size add the node
  3. Visit right before left

Problem 316: Check for Symmetrical Binary Treemedium

Question Statement

Mirror of itself.

Input: root=[1,2,2,3,4,4,3]
Output:
true

Brute force

Invert a copy and compare.

Optimized idea

Recursively compare mirrored children.

Why it works

A tree is symmetric when left and right are mirrors.

Java implementation

public static boolean isSymmetric(TreeNode root) {
    return root == null || mirror(root.left, root.right);
}

private static boolean mirror(TreeNode a, TreeNode b) {
    if (a == null || b == null) return a == b;
    return a.val == b.val && mirror(a.left, b.right) && mirror(a.right, b.left);
}

Explanation

  1. Compare left.left with right.right
  2. Compare left.right with right.left
  3. Values must match

Problem 317: Root to Node Pathmedium

Question Statement

Path from root to node x.

Input: root=[1,2,3,4,5,6,7], x=7
Output:
[1,3,7]

Brute force

Find all paths and filter.

Optimized idea

DFS adding nodes and backtracking.

Why it works

The first path reaching x is the unique root-to-node path.

Java implementation

public static List<Integer> rootToNode(TreeNode root, int x) {
    List<Integer> path = new ArrayList<>();
    find(root, x, path);
    return path;
}

private static boolean find(TreeNode n, int x, List<Integer> p) {
    if (n == null) return false;
    p.add(n.val);
    if (n.val == x || find(n.left, x, p) || find(n.right, x, p)) return true;
    p.remove(p.size() - 1);
    return false;
}

Explanation

  1. Add the node
  2. If value == x return true
  3. Recurse into children
  4. Remove the node if not found

Problem 318: Lowest Common Ancestormedium

Question Statement

LCA of two nodes.

Input: root=[3,5,1,6,2,0,8], p=5, q=1
Output:
3

Brute force

Find both root paths and compare them.

Optimized idea

One recursion returning the node if it matches or found in subtrees.

Why it works

The first node where p and q split between subtrees is the LCA.

Java implementation

public static TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode l = lowestCommonAncestor(root.left, p, q), r = lowestCommonAncestor(root.right, p, q);

private static int[] go(TreeNode n, int[] best) {
    if (n == null) return new int[]{Integer.MAX_VALUE, Integer.MIN_VALUE, 0};
    int[] l = go(n.left, best), r = go(n.right, best);

        int size = l[2] + r[2] + 1;
        best[0] = Math.max(best[0], size);
        return new int[]{Math.min(l[0], n.val), Math.max(r[1], n.val), size};
    }
    return new int[]{Integer.MIN_VALUE, Integer.MAX_VALUE, Math.max(l[2], r[2])};
}

Explanation

  1. Null returns an empty BST
  2. Combine children if valid
  3. Otherwise mark invalid
  4. Track the largest size
