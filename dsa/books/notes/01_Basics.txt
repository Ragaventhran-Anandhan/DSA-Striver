opt: Same nested loops; n rows, each with n stars, is already optimal for output size.
why: Output has n*n characters, so O(n^2) is the minimum.
expl: Loop i over rows | Loop j over columns and print * | Print a newline after each row

=== 26
brute: Try every number from min(a,b) down to 1.
opt: Euclid: gcd(a, b) = gcd(b, a % b).
why: Common divisors of a and b are the same as those of b and a mod b.
expl: While b != 0 | Replace (a, b) with (b, a % b) | Return a
code:
public static int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}
=== 27
brute: Convert to string and use Math.pow per digit.
opt: Count digits then sum digit^count by integer multiplication.
why: Armstrong definition is exactly that sum.
expl: Count digits k | Sum each digit raised to k | Compare with n
code:
public static boolean isArmstrong(int n) {
    int k = String.valueOf(n).length(), sum = 0, t = n;
    while (t > 0) {
        int d = t % 10, p = 1;
        for (int i = 0; i < k; i++) p *= d;
        sum += p;
        t /= 10;
    }
    return sum == n;
}
=== 28
brute: Check every i from 1 to n.
opt: Check i up to sqrt(n); each i gives divisors i and n/i.
why: Divisors come in pairs around sqrt(n).
expl: Loop i while i*i <= n | If i divides n add i to the front list | Add n/i to the back list if different | Join front and reversed back
code:
public static List<Integer> divisors(int n) {
    List<Integer> small = new ArrayList<>(), large = new ArrayList<>();
    for (int i = 1; (long) i * i <= n; i++) {
        if (n % i == 0) {
            small.add(i);
            if (i != n / i) large.add(n / i);
        }
    }
    Collections.reverse(large);
    small.addAll(large);
    return small;
}

=== 31
brute: Run isPrime on every number below n.
opt: Sieve of Eratosthenes.
why: Marking multiples of each prime removes all composites in O(n log log n).
expl: Boolean array initialised to prime | For each prime p, mark p*p, p*p+p, ... composite | Count unmarked numbers from 2 to n-1
code:
public static int countPrimes(int n) {
    if (n < 3) return 0;
    boolean[] comp = new boolean[n];
    int count = 0;
    for (int i = 2; i < n; i++) {
        if (!comp[i]) {
            count++;
            for (long j = (long) i * i; j < n; j += i) comp[(int) j] = true;
        }
    }
    return count;
}

private static void reverseHelper(int[] arr, int l, int r) {

    int t = arr[l]; arr[l] = arr[r]; arr[r] = t;
    reverseHelper(arr, l + 1, r - 1);

public static int fibonacci(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}

=== 43
brute: Count each element by scanning, O(n^2).
opt: Build a frequency map and scan it for max and min with tie-breaking.
why: One pass for counts and one over distinct keys is O(n).
expl: Count frequencies | Track the best max (ties pick smaller) | Track the best min (ties pick smaller) | Return both
code:
public static int[] highLowFrequency(int[] arr) {
    Map<Integer, Integer> m = new HashMap<>();
    for (int x : arr) m.merge(x, 1, Integer::sum);
    int hi = -1, lo = -1, hf = 0, lf = Integer.MAX_VALUE;
    for (Map.Entry<Integer, Integer> e : m.entrySet()) {
        int k = e.getKey(), f = e.getValue();
        if (f > hf || (f == hf && k < hi)) { hf = f; hi = k; }
        if (f < lf || (f == lf && k < lo)) { lf = f; lo = k; }
    }
    return new int[]{hi, lo};
}
