Problem 449: Implement Trie (Prefix Tree)medium

Question Statement

insert, search, startsWith.

Input: insert("apple") search("apple") startsWith("app")
Output:
true, true

Brute force

Store words in a list and scan for every query.

Optimized idea

Trie with 26 children per node and an end-of-word flag.

Why it works

Insert, search and prefix queries cost O(length of the word), independent of the number of words.

Java implementation

public static void implementTrie() {
    class Node { Node[] ch = new Node[26]; boolean end; }
    class Trie {
        Node root = new Node();
        void insert(String w) {
            Node n = root;
            for (char c : w.toCharArray()) {
                if (n.ch[c - 'a'] == null) n.ch[c - 'a'] = new Node();
                n = n.ch[c - 'a'];
            }
            n.end = true;
        }
        Node walk(String p) {
            Node n = root;
            for (char c : p.toCharArray()) {
                n = n.ch[c - 'a'];
                if (n == null) return null;
            }
            return n;
        }
        boolean search(String w) { Node n = walk(w); return n != null && n.end; }
        boolean startsWith(String p) { return walk(p) != null; }
    }
    Trie t = new Trie();
    t.insert("apple");
    System.out.println(t.search("apple"));
    System.out.println(t.startsWith("app"));
}

Explanation

  1. Each node holds children[26] and isEnd
  2. insert walks and creates missing nodes
  3. search checks isEnd at the last node
  4. startsWith only needs the path to exist

Problem 450: Implement Trie IImedium

Question Statement

countWordsEqualTo, countWordsStartingWith, erase.

Input: insert("apple") countWordsEqualTo("apple")
Output:
1

Brute force

Count by scanning all stored words.

Optimized idea

Trie nodes storing prefix and end counters.

Why it works

Counters give each query answer in O(length); erase decrements the counters along the path.

Java implementation

public static void implementTrieII() {
    class Node { Node[] ch = new Node[26]; int end, prefix; }
    class Trie {
        Node root = new Node();
        void insert(String w) {
            Node n = root;
            for (char c : w.toCharArray()) {
                if (n.ch[c - 'a'] == null) n.ch[c - 'a'] = new Node();
                n = n.ch[c - 'a'];
                n.prefix++;
            }
            n.end++;
        }
        int countWordsEqualTo(String w) {
            Node n = root;
            for (char c : w.toCharArray()) { n = n.ch[c - 'a']; if (n == null) return 0; }
            return n.end;
        }
        int countWordsStartingWith(String p) {
            Node n = root;
            for (char c : p.toCharArray()) { n = n.ch[c - 'a']; if (n == null) return 0; }
            return n.prefix;
        }
        void erase(String w) {
            if (countWordsEqualTo(w) == 0) return;
            Node n = root;
            for (char c : w.toCharArray()) { n = n.ch[c - 'a']; n.prefix--; }
            n.end--;
        }
    }
    Trie t = new Trie();
    t.insert("apple");
    System.out.println(t.countWordsEqualTo("apple"));
}

Explanation

  1. insert increments prefixCount on every node and endCount at the last
  2. countWordsEqualTo reads endCount
  3. countWordsStartingWith reads prefixCount
  4. erase decrements the same counters

Problem 451: Longest Word with All Prefixesmedium

Question Statement

Longest word whose all prefixes exist.

Input: words=["n","ni","nin","ninj","ninja","ninga"]
Output:
"ninja"

Brute force

For every word check each prefix with a list search.

Optimized idea

Insert all words into a trie and check that every prefix node is an end.

Why it works

A word qualifies only if each node on its path is marked as a word end.

Java implementation

public static String completeString(String[] words) {
    class Node { Node[] ch = new Node[26]; boolean end; }
    Node root = new Node();
    for (String w : words) {
        Node n = root;
        for (char c : w.toCharArray()) {
            if (n.ch[c - 'a'] == null) n.ch[c - 'a'] = new Node();
            n = n.ch[c - 'a'];
        }
        n.end = true;
    }
    String best = "";
    for (String w : words) {
        Node n = root;
        boolean ok = true;
        for (char c : w.toCharArray()) {
            n = n.ch[c - 'a'];
            if (!n.end) { ok = false; break; }
        }
        if (ok && (w.length() > best.length() || (w.length() == best.length() && w.compareTo(best) < 0))) best = w;
    }
    return best;
}

Explanation

  1. Build the trie
  2. For each word walk it and require end at every step
  3. Keep the longest, ties lexicographically smaller

Problem 452: Number of Distinct Substrings in a Stringmedium

Question Statement

Count using a trie.

Input: s="abab"
Output:
7

Brute force

Put every substring in a HashSet, O(n^3).

Optimized idea

Insert every suffix in a trie and count created nodes.

Why it works

Every distinct substring is a prefix of exactly one path, i.e. one trie node.

Java implementation

public static int countDistinctSubstrings(String s) {
    class Node { Node[] ch = new Node[26]; }
    Node root = new Node();
    int count = 0;
    for (int i = 0; i < s.length(); i++) {
        Node n = root;
        for (int j = i; j < s.length(); j++) {
            int c = s.charAt(j) - 'a';
            if (n.ch[c] == null) { n.ch[c] = new Node(); count++; }
            n = n.ch[c];
        }
    }
    return count;
}

Explanation

  1. For each suffix walk the trie
  2. Count each newly created node
  3. The count equals the distinct substrings

Problem 453: Maximum XOR of Two Numbers in an Arrayhard

Question Statement

Max XOR pair.

Input: arr=[3,10,5,25,2,8]
Output:
28

Brute force

Try every pair, O(n^2).

Optimized idea

Binary trie; for each number greedily choose the opposite bit.

Why it works

A higher bit that differs outweighs all lower bits, so greedy is optimal.

Java implementation

public static int findMaximumXOR(int[] arr) {
    class Node { Node[] ch = new Node[2]; }
    Node root = new Node();
    for (int x : arr) {
        Node n = root;
        for (int b = 31; b >= 0; b--) {
            int bit = (x >> b) & 1;
            if (n.ch[bit] == null) n.ch[bit] = new Node();
            n = n.ch[bit];
        }
    }
    int best = 0;
    for (int x : arr) {
        Node n = root;
        int cur = 0;
        for (int b = 31; b >= 0; b--) {
            int bit = (x >> b) & 1;
            if (n.ch[1 - bit] != null) { cur |= 1 << b; n = n.ch[1 - bit]; }
            else n = n.ch[bit];
        }
        best = Math.max(best, cur);
    }
    return best;
}

Explanation

  1. Insert numbers bit by bit from bit 31
  2. For each number walk preferring the opposite bit
  3. Track the max XOR

Problem 454: Maximum XOR with an Element from Arrayhard

Question Statement

Max XOR with limit.

Input: arr=[0,1,2,3,4], queries=[[3,1],[1,3],[5,6]]
Output:
[3,3,7]

Brute force

For each query scan all elements <= limit.

Optimized idea

Offline: sort queries by limit and insert elements into the trie incrementally.

Why it works

Each query then runs the greedy trie walk on exactly the allowed elements.

Java implementation

public static int[] maximizeXor(int[] arr, int[][] queries) {
    class Node { Node[] ch = new Node[2]; }
    Node root = new Node();
    int[] a = arr.clone();
    Arrays.sort(a);
    Integer[] order = new Integer[queries.length];
    for (int i = 0; i < order.length; i++) order[i] = i;
    Arrays.sort(order, (x, y) -> queries[x][1] - queries[y][1]);
    int[] res = new int[queries.length];
    int p = 0;
    for (int qi : order) {
        while (p < a.length && a[p] <= queries[qi][1]) {
            Node n = root;
            for (int b = 31; b >= 0; b--) {
                int bit = (a[p] >> b) & 1;
                if (n.ch[bit] == null) n.ch[bit] = new Node();
                n = n.ch[bit];
            }
            p++;
        }
        if (p == 0) { res[qi] = -1; continue; }
        Node n = root;
        int x = queries[qi][0], cur = 0;
        for (int b = 31; b >= 0; b--) {
            int bit = (x >> b) & 1;
            if (n.ch[1 - bit] != null) { cur |= 1 << b; n = n.ch[1 - bit]; }
            else n = n.ch[bit];
        }
        res[qi] = cur;
    }
    return res;
}

Explanation

  1. Sort arr and queries by limit
  2. Insert elements <= limit
  3. If trie is empty answer -1
  4. Else greedy max XOR
