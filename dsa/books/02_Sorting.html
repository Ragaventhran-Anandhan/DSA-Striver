Problem 44: Selection Sorteasy

Question Statement

Sort ascending using selection sort.

Input: arr=[13,46,24,52,20,9]
Output:
[9,13,20,24,46,52]

Brute force

Repeatedly find the minimum with a full scan and copy into a new array.

Optimized idea

Selection sort: swap the minimum of the unsorted part into position i.

Why it works

After pass i, the first i+1 positions hold the i+1 smallest values in order.

Java implementation

public static void selectionSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        int min = i;
        for (int j = i + 1; j < arr.length; j++) if (arr[j] < arr[min]) min = j;
        int t = arr[i]; arr[i] = arr[min]; arr[min] = t;
    }
}

Explanation

  1. For i from 0 to n-2
  2. Find index of the minimum in [i, n-1]
  3. Swap it with arr[i]

Problem 45: Bubble Sorteasy

Question Statement

Sort ascending using bubble sort.

Input: arr=[13,46,24,52,20,9]
Output:
[9,13,20,24,46,52]

Brute force

Compare every pair and swap if out of order.

Optimized idea

Bubble adjacent pairs; stop early if a pass makes no swap.

Why it works

Each pass pushes the largest remaining element to the end.

Java implementation

public static void bubbleSort(int[] arr) {
    for (int i = arr.length - 1; i > 0; i--) {
        boolean swapped = false;
        for (int j = 0; j < i; j++) {
            if (arr[j] > arr[j + 1]) {
                int t = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = t;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

Explanation

  1. For i from n-1 down to 1
  2. Swap adjacent out-of-order pairs in [0, i]
  3. Break if nothing swapped

Problem 46: Insertion Sorteasy

Question Statement

Sort ascending using insertion sort.

Input: arr=[13,46,24,52,20,9]
Output:
[9,13,20,24,46,52]

Brute force

Insert each element into a new sorted list.

Optimized idea

Insertion sort in place: shift larger elements right then drop the key.

Why it works

Prefix [0, i-1] is always sorted, so inserting arr[i] keeps it sorted.

Java implementation

public static void insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int key = arr[i], j = i - 1;
        while (j >= 0 && arr[j] > key) { arr[j + 1] = arr[j]; j--; }
        arr[j + 1] = key;
    }
}

Explanation

  1. For i from 1
  2. key = arr[i]
  3. Shift greater elements one step right
  4. Place key in the gap

Problem 47: Recursive Bubble Sorteasy

Question Statement

Bubble sort using recursion.

Input: arr=[5,3,1]
Output:
[1,3,5]

Brute force

Iterative bubble sort.

Optimized idea

Recursion: one bubble pass for size n, then recurse on n-1.

Why it works

After one pass the maximum is fixed at the end, reducing the problem by one.

Java implementation

public static void recursiveBubbleSort(int[] arr) {
    bubble(arr, arr.length);
}

private static void bubble(int[] a, int n) {
    if (n <= 1) return;
    for (int j = 0; j < n - 1; j++)
        if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; }
    bubble(a, n - 1);
}

Explanation

  1. If n == 1 return
  2. Bubble the largest to index n-1
  3. Recurse with n-1

Problem 48: Recursive Insertion Sorteasy

Question Statement

Insertion sort using recursion.

Input: arr=[5,3,1]
Output:
[1,3,5]

Brute force

Iterative insertion sort.

Optimized idea

Recursively sort the first n-1 elements then insert the n-th.

Why it works

Induction: sorted prefix plus one insertion gives a sorted prefix.

Java implementation

public static void recursiveInsertionSort(int[] arr) {
    insertion(arr, arr.length);
}

private static void insertion(int[] a, int n) {
    if (n <= 1) return;
    insertion(a, n - 1);
    int key = a[n - 1], j = n - 2;
    while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
    a[j + 1] = key;
}

Explanation

  1. If n <= 1 return
  2. Recurse on n-1
  3. Insert a[n-1] into the sorted prefix

Problem 49: Merge Sortmedium

Question Statement

Sort ascending using merge sort.

Input: arr=[9,4,7,6,3,1,5]
Output:
[1,3,4,5,6,7,9]

Brute force

O(n^2) sorts.

Optimized idea

Divide and conquer: split, sort halves, merge.

Why it works

Merging two sorted halves is linear and the depth is log n, giving O(n log n).

Java implementation

public static void mergeSort(int[] arr) {
    sort(arr, 0, arr.length - 1);
}

private static void sort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int mid = (lo + hi) / 2;
    sort(a, lo, mid);
    sort(a, mid + 1, hi);
    int[] tmp = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi) tmp[k++] = a[j++];
    System.arraycopy(tmp, 0, a, lo, tmp.length);
}

Explanation

  1. Split at mid
  2. Sort left and right
  3. Merge using a temp array
  4. Copy back

Problem 50: Quick Sortmedium

Question Statement

Sort ascending using quick sort.

Input: arr=[4,6,2,5,7,9,1,3]
Output:
[1,2,3,4,5,6,7,9]

Brute force

O(n^2) sorts.

Optimized idea

Quick sort: partition around a pivot then sort both sides.

Why it works

After partitioning, the pivot is in its final place; average depth is log n.

Java implementation

public static void quickSort(int[] arr) {
    qs(arr, 0, arr.length - 1);
}

private static void qs(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = a[hi], i = lo;
    for (int j = lo; j < hi; j++)
        if (a[j] < pivot) { int t = a[i]; a[i] = a[j]; a[j] = t; i++; }
    int t = a[i]; a[i] = a[hi]; a[hi] = t;
    qs(a, lo, i - 1);
    qs(a, i + 1, hi);
}

Explanation

  1. Choose pivot as the last element
  2. Move smaller elements before it
  3. Place pivot
  4. Recurse on both sides
