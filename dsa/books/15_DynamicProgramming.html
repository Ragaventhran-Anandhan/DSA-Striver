Problem 391: Climbing Stairseasy

Question Statement

Distinct ways to climb n steps (1 or 2).

Input: n=3
Output:
3

Brute force

Plain recursion f(n) = f(n-1) + f(n-2), O(2^n).

Optimized idea

Bottom-up DP keeping the last two values.

Why it works

Ways to reach step n come from the two previous steps.

Java implementation

public static int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) { int c = a + b; a = b; b = c; }
    return b;
}

Explanation

  1. dp[1] = 1, dp[2] = 2
  2. dp[i] = dp[i-1] + dp[i-2]
  3. Keep only two variables

Problem 392: Frog Jumpmedium

Question Statement

Min energy, jump 1 or 2 steps.

Input: heights=[10,20,30,10]
Output:
20

Brute force

Recursion trying both jumps from each stair.

Optimized idea

DP: dp[i] = min(dp[i-1] + |h[i]-h[i-1]|, dp[i-2] + |h[i]-h[i-2]|).

Why it works

The best cost to stair i depends only on the previous two stairs.

Java implementation

public static int frogJump(int[] heights) {
    int n = heights.length;
    if (n == 1) return 0;
    int prev2 = 0, prev = Math.abs(heights[1] - heights[0]);
    for (int i = 2; i < n; i++) {
        int cur = Math.min(prev + Math.abs(heights[i] - heights[i - 1]), prev2 + Math.abs(heights[i] - heights[i - 2]));
        prev2 = prev;
        prev = cur;
    }
    return prev;
}

Explanation

  1. dp[0] = 0
  2. Compute one-step and two-step costs
  3. Keep two variables

Problem 393: Frog Jump with K Distancesmedium

Question Statement

Jump up to k steps.

Input: heights=[10,5,20,0,15], k=2
Output:
15

Brute force

Recursion over up to k jumps from each stair.

Optimized idea

DP where dp[i] is the min over the last k stairs.

Why it works

Each stair looks back at most k stairs, O(nk).

Java implementation

public static int frogJumpK(int[] heights, int k) {
    int n = heights.length;
    int[] dp = new int[n];
    for (int i = 1; i < n; i++) {
        dp[i] = Integer.MAX_VALUE;
        for (int j = 1; j <= k && i - j >= 0; j++)
            dp[i] = Math.min(dp[i], dp[i - j] + Math.abs(heights[i] - heights[i - j]));
    }
    return dp[n - 1];
}

Explanation

  1. dp[0] = 0
  2. For each i try j from 1 to k
  3. dp[i] = min(dp[i-j] + |h[i]-h[i-j]|)

Problem 394: Maximum Sum of Non-Adjacent Elementsmedium

Question Statement

House Robber I variant.

Input: arr=[2,1,4,9]
Output:
11

Brute force

Recursion picking or skipping each element.

Optimized idea

DP with prev and prev2.

Why it works

Taking element i means the best of i-2 and below, skipping means the best of i-1.

Java implementation

public static int maxNonAdjacentSum(int[] arr) {
    int prev = 0, prev2 = 0;
    for (int x : arr) {
        int cur = Math.max(x + prev2, prev);
        prev2 = prev;
        prev = cur;
    }
    return prev;
}

Explanation

  1. take = arr[i] + prev2
  2. skip = prev
  3. cur = max(take, skip)

Problem 395: House Robber IImedium

Question Statement

Houses in a circle.

Input: arr=[2,3,2]
Output:
3

Brute force

Try all circular selections.

Optimized idea

Run the linear solution twice: without the first and without the last house.

Why it works

The first and last houses are adjacent, so at most one of them is used.

Java implementation

public static int robCircular(int[] arr) {
    int n = arr.length;
    if (n == 1) return arr[0];
    return Math.max(rob(arr, 0, n - 2), rob(arr, 1, n - 1));
}

private static int rob(int[] a, int l, int r) {
    int prev = 0, prev2 = 0;
    for (int i = l; i <= r; i++) {
        int cur = Math.max(a[i] + prev2, prev);
        prev2 = prev;
        prev = cur;
    }
    return prev;
}

Explanation

  1. If n == 1 return arr[0]
  2. max(rob(0..n-2), rob(1..n-1))

Problem 396: Ninja's Trainingmedium

Question Statement

Max points, no same activity on consecutive days.

Input: points=[[10,40,70],[20,50,80],[30,60,90]]
Output:
210

Brute force

Recursion over days and last activity, O(3^n).

Optimized idea

DP table dp[day][last].

Why it works

The best total for a day depends only on the previous day's best per activity.

Java implementation

public static int ninjaTraining(int[][] points) {
    int n = points.length;
    int[] prev = points[0].clone();
    for (int i = 1; i < n; i++) {
        int[] cur = new int[3];
        for (int a = 0; a < 3; a++)
            for (int b = 0; b < 3; b++) if (a != b) cur[a] = Math.max(cur[a], points[i][a] + prev[b]);
        prev = cur;
    }
    return Math.max(prev[0], Math.max(prev[1], prev[2]));
}

Explanation

  1. dp[0][a] = points[0][a]
  2. dp[i][a] = points[i][a] + max over b != a of dp[i-1][b]
  3. Answer is the max of the last day

Problem 397: Unique Pathsmedium

Question Statement

Paths from top-left to bottom-right.

Input: m=3, n=7
Output:
28

Brute force

Recursion right or down, O(2^(m+n)).

Optimized idea

1D DP: dp[j] += dp[j-1].

Why it works

Paths to a cell equal paths from above plus paths from the left.

Java implementation

public static int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++) dp[j] += dp[j - 1];
    return dp[n - 1];
}

Explanation

  1. dp filled with 1
  2. For each next row dp[j] += dp[j-1]
  3. Return dp[n-1]

Problem 398: Unique Paths II (Obstacles)medium

Question Statement

Grid with obstacles.

Input: grid=[[0,0,0],[0,1,0],[0,0,0]]
Output:
2

Brute force

Recursion avoiding obstacles.

Optimized idea

DP with obstacle cells set to 0 ways.

Why it works

A blocked cell contributes no paths.

Java implementation

public static int uniquePathsWithObstacles(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];
    dp[0] = grid[0][0] == 0 ? 1 : 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 1) dp[j] = 0;
            else if (j > 0) dp[j] += dp[j - 1];
        }
    return dp[n - 1];
}

Explanation

  1. dp[0][0] = 1 if open
  2. Obstacle cell = 0
  3. Otherwise add top and left

Problem 399: Minimum Path Sum in Gridmedium

Question Statement

Min sum path.

Input: grid=[[1,3,1],[1,5,1],[4,2,1]]
Output:
7

Brute force

Recursion over all paths.

Optimized idea

DP: each cell adds the cheaper of top and left.

Why it works

The cheapest path to a cell comes through one of its two predecessors.

Java implementation

public static int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++) {
            if (i == 0 && j == 0) dp[j] = grid[0][0];
            else if (i == 0) dp[j] = dp[j - 1] + grid[i][j];
            else if (j == 0) dp[j] += grid[i][j];
            else dp[j] = grid[i][j] + Math.min(dp[j], dp[j - 1]);
        }
    return dp[n - 1];
}

Explanation

  1. dp[0][0] = grid[0][0]
  2. First row and column accumulate
  3. dp[i][j] = grid[i][j] + min(up, left)

Problem 400: Triangle (Minimum Path Sum)medium

Question Statement

Top to bottom min path.

Input: triangle=[[2],[3,4],[6,5,7],[4,1,8,3]]
Output:
11

Brute force

Recursion down each path.

Optimized idea

Bottom-up DP starting from the last row.

Why it works

Each node adds the smaller of its two children's best totals.

Java implementation

public static int minimumTotal(List<List<Integer>> triangle) {
    int n = triangle.size();
    int[] dp = new int[n];
    for (int j = 0; j < n; j++) dp[j] = triangle.get(n - 1).get(j);
    for (int i = n - 2; i >= 0; i--)
        for (int j = 0; j <= i; j++) dp[j] = triangle.get(i).get(j) + Math.min(dp[j], dp[j + 1]);
    return dp[0];
}

Explanation

  1. dp = last row
  2. For rows above dp[j] = val + min(dp[j], dp[j+1])
  3. Answer dp[0]

Problem 401: Minimum/Maximum Falling Path Summedium

Question Statement

Min falling path.

Input: matrix=[[2,1,3],[6,5,4],[7,8,9]]
Output:
13

Brute force

Recursion over three directions.

Optimized idea

DP row by row using the three cells above.

Why it works

A falling path moves to the same, left or right column.

Java implementation

public static int minFallingPathSum(int[][] matrix) {
    int n = matrix.length, m = matrix[0].length;
    int[] prev = matrix[0].clone();
    for (int i = 1; i < n; i++) {
        int[] cur = new int[m];
        for (int j = 0; j < m; j++) {
            int best = prev[j];
            if (j > 0) best = Math.min(best, prev[j - 1]);
            if (j < m - 1) best = Math.min(best, prev[j + 1]);
            cur[j] = matrix[i][j] + best;
        }
        prev = cur;
    }
    int res = Integer.MAX_VALUE;
    for (int x : prev) res = Math.min(res, x);
    return res;
}

Explanation

  1. Start with the first row
  2. cur[j] = m[i][j] + min(prev[j-1], prev[j], prev[j+1])
  3. Answer is the min of the last row

Problem 402: Subset Sum Equals to Targetmedium

Question Statement

Subset with sum k?

Input: arr=[1,2,3,4], k=4
Output:
true

Brute force

Try all 2^n subsets.

Optimized idea

1D boolean DP over sums.

Why it works

dp[s] is true if s can be formed from the elements considered so far.

Java implementation

public static boolean subsetSumToK(int[] arr, int k) {
    boolean[] dp = new boolean[k + 1];
    dp[0] = true;
    for (int x : arr)
        for (int s = k; s >= x; s--) dp[s] |= dp[s - x];
    return dp[k];
}

Explanation

  1. dp[0] = true
  2. For each element iterate s from k down to value
  3. dp[s] |= dp[s - value]

Problem 403: Partition Equal Subset Summedium

Question Statement

Split into two equal-sum subsets.

Input: arr=[1,5,11,5]
Output:
true

Brute force

Try all subsets for half the total.

Optimized idea

Subset sum to total/2.

Why it works

Two equal parts exist iff a subset sums to half.

Java implementation

public static boolean canPartition(int[] arr) {
    int total = 0;
    for (int x : arr) total += x;
    if (total % 2 != 0) return false;
    int k = total / 2;
    boolean[] dp = new boolean[k + 1];
    dp[0] = true;
    for (int x : arr)
        for (int s = k; s >= x; s--) dp[s] |= dp[s - x];
    return dp[k];
}

Explanation

  1. Odd total returns false
  2. Run subset sum with target total/2

Problem 404: Partition Set into Two Subsets with Minimum Absolute Sum Differencemedium

Question Statement

Minimize difference.

Input: arr=[1,6,11,5]
Output:
1

Brute force

Try all subsets and compare sums.

Optimized idea

Subset sum table; choose the reachable sum closest to total/2.

Why it works

diff = total - 2*s1 is minimized when s1 is nearest to half.

Java implementation

public static int minSubsetSumDifference(int[] arr) {
    int total = 0;
    for (int x : arr) total += x;
    boolean[] dp = new boolean[total + 1];
    dp[0] = true;
    for (int x : arr)
        for (int s = total; s >= x; s--) dp[s] |= dp[s - x];
    int best = Integer.MAX_VALUE;
    for (int s = 0; s <= total / 2; s++) if (dp[s]) best = Math.min(best, total - 2 * s);
    return best;
}

Explanation

  1. Build reachable sums up to total
  2. For s <= total/2 that is reachable minimize total - 2s

Problem 406: Count Partitions with Given Differencemedium

Question Statement

Subsets S1-S2=d.

Input: arr=[5,2,6,4], d=3
Output:
1

Brute force

Try all subset assignments.

Optimized idea

Reduce to counting subsets with sum (total - d)/2.

Why it works

S1 - S2 = d and S1 + S2 = total give S1 = (total + d)/2 (equivalently S2 = (total-d)/2).

Java implementation

public static int countPartitions(int[] arr, int d) {
    int total = 0;
    for (int x : arr) total += x;
    if (total - d < 0 || (total - d) % 2 != 0) return 0;
    int k = (total - d) / 2;
    int[] dp = new int[k + 1];
    dp[0] = 1;
    for (int x : arr)
        for (int s = k; s >= x; s--) dp[s] += dp[s - x];
    return dp[k];
}

Explanation

  1. If total - d is negative or odd return 0
  2. target = (total - d)/2
  3. Count subsets with that sum

Problem 407: 0/1 Knapsackmedium

Question Statement

Max value.

Input: wt=[1,2,4,5], val=[5,4,8,6], w=5
Output:
13

Brute force

Recursion picking or skipping each item.

Optimized idea

1D DP iterating capacity downwards.

Why it works

Going downward uses each item at most once.

Java implementation

public static int knapsack(int[] wt, int[] val, int w) {
    int[] dp = new int[w + 1];
    for (int i = 0; i < wt.length; i++)
        for (int c = w; c >= wt[i]; c--) dp[c] = Math.max(dp[c], dp[c - wt[i]] + val[i]);
    return dp[w];
}

Explanation

  1. dp[c] = best value with capacity c
  2. For each item for c from W to wt
  3. dp[c] = max(dp[c], dp[c-wt] + val)

Problem 408: Minimum Coinsmedium

Question Statement

Fewest coins, -1 if impossible.

Input: coins=[1,2,5], amount=11
Output:
3

Brute force

Recursion trying every coin.

Optimized idea

DP over amounts.

Why it works

The fewest coins for an amount is one plus the best for the remainder.

Java implementation

public static int coinChange(int[] coins, int amount) {
    int INF = amount + 1;
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, INF);
    dp[0] = 0;
    for (int a = 1; a <= amount; a++)
        for (int c : coins) if (c <= a) dp[a] = Math.min(dp[a], dp[a - c] + 1);
    return dp[amount] >= INF ? -1 : dp[amount];
}

Explanation

  1. dp[0] = 0, others INF
  2. For each amount try each coin
  3. Return -1 if INF

Problem 409: Target Summedium

Question Statement

Assign +/- to reach target.

Input: arr=[1,1,1,1,1], target=3
Output:
5

Brute force

Try all 2^n sign choices.

Optimized idea

Count subsets with sum (total + target)/2.

Why it works

With P positives and N negatives, P - N = target and P + N = total.

Java implementation

public static int findTargetSumWays(int[] arr, int target) {
    int total = 0;
    for (int x : arr) total += x;
    if (Math.abs(target) > total || (total + target) % 2 != 0) return 0;
    int s = (total + target) / 2;
    int[] dp = new int[s + 1];
    dp[0] = 1;
    for (int x : arr)
        for (int j = s; j >= x; j--) dp[j] += dp[j - x];
    return dp[s];
}

Explanation

  1. Check parity and range
  2. s = (total + target)/2
  3. Count subsets summing to s

Problem 412: Rod Cutting Problemmedium

Question Statement

Max profit from rod.

Input: price=[2,5,7,8,10], n=5
Output:
12

Brute force

Recursively try every first cut.

Optimized idea

Unbounded knapsack with piece lengths 1..n.

Why it works

Each piece length is available any number of times.

Java implementation

public static int cutRod(int[] price, int n) {
    int[] dp = new int[n + 1];
    for (int len = 1; len <= n; len++)
        for (int i = 1; i <= len; i++) dp[len] = Math.max(dp[len], price[i - 1] + dp[len - i]);
    return dp[n];
}

Explanation

  1. dp[len] = best profit
  2. Try every cut length i
  3. dp[len] = max(dp[len], price[i-1] + dp[len-i])

Problem 413: Longest Common Subsequencemedium

Question Statement

LCS length.

Input: a="abcde", b="ace"
Output:
3

Brute force

Recursion over all subsequences.

Optimized idea

2D DP table.

Why it works

dp[i][j] extends the diagonal on a match or takes the better of skipping one character.

Java implementation

public static int longestCommonSubsequence(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] dp = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1) ? dp[i - 1][j - 1] + 1 : Math.max(dp[i - 1][j], dp[i][j - 1]);
    return dp[n][m];
}

Explanation

  1. dp sized (n+1) x (m+1)
  2. Equal chars: dp[i-1][j-1] + 1
  3. Else max(dp[i-1][j], dp[i][j-1])

Problem 414: Print Longest Common Subsequencemedium

Question Statement

Return LCS.

Input: a="abcde", b="ace"
Output:
"ace"

Brute force

Generate all subsequences and compare.

Optimized idea

Build the LCS table then walk back.

Why it works

The table tells which move produced each value.

Java implementation

public static String printLCS(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] dp = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1) ? dp[i - 1][j - 1] + 1 : Math.max(dp[i - 1][j], dp[i][j - 1]);
    StringBuilder sb = new StringBuilder();
    int i = n, j = m;
    while (i > 0 && j > 0) {
        if (a.charAt(i - 1) == b.charAt(j - 1)) { sb.append(a.charAt(i - 1)); i--; j--; }
        else if (dp[i - 1][j] >= dp[i][j - 1]) i--;
        else j--;
    }
    return sb.reverse().toString();
}

Explanation

  1. Fill the table
  2. From (n, m) go diagonally on a match and append the char
  3. Otherwise move toward the larger neighbour
  4. Reverse the result

Problem 415: Longest Common Substringmedium

Question Statement

Length.

Input: a="abcjklp", b="acjkp"
Output:
3

Brute force

Compare every pair of substrings.

Optimized idea

DP where a mismatch resets the count to 0.

Why it works

A common substring must be contiguous, so dp[i][j] depends only on the diagonal.

Java implementation

public static int longestCommonSubstring(String a, String b) {
    int n = a.length(), m = b.length(), best = 0;
    int[][] dp = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (a.charAt(i - 1) == b.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
                best = Math.max(best, dp[i][j]);
            }
    return best;
}

Explanation

  1. Equal chars: dp[i][j] = dp[i-1][j-1] + 1
  2. Else 0
  3. Track the max

Problem 416: Longest Palindromic Subsequencemedium

Question Statement

Length.

Input: s="bbbab"
Output:
4

Brute force

Recursion over all subsequences.

Optimized idea

LCS of the string and its reverse.

Why it works

A palindromic subsequence reads the same forward and backward.

Java implementation

public static int longestPalindromeSubseq(String s) {
    String r = new StringBuilder(s).reverse().toString();

Problem 419: Shortest Common Supersequencemedium

Question Statement

Shortest string containing both.

Input: a="brute", b="groot"
Output:
"bgruoote"

Brute force

Try all interleavings.

Optimized idea

Use the LCS table and walk back, emitting characters from both strings.

Why it works

Characters in the LCS are shared, all others appear once.

Java implementation

public static String shortestCommonSupersequence(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] dp = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1) ? dp[i - 1][j - 1] + 1 : Math.max(dp[i - 1][j], dp[i][j - 1]);
    StringBuilder sb = new StringBuilder();
    int i = n, j = m;
    while (i > 0 && j > 0) {
        if (a.charAt(i - 1) == b.charAt(j - 1)) { sb.append(a.charAt(i - 1)); i--; j--; }
        else if (dp[i - 1][j] > dp[i][j - 1]) sb.append(a.charAt(--i));
        else sb.append(b.charAt(--j));
    }
    while (i > 0) sb.append(a.charAt(--i));
    while (j > 0) sb.append(b.charAt(--j));
    return sb.reverse().toString();
}

Explanation

  1. Build the LCS table
  2. From (n, m): match emits one char
  3. Otherwise emit from the larger side
  4. Append leftovers and reverse

public static int cherryPickup(int[][] grid) {
    int r = grid.length, c = grid[0].length;
    int[][] dp = new int[c][c];
    for (int[] row : dp) Arrays.fill(row, Integer.MIN_VALUE);

        sell1 = Math.max(sell1, buy1 + p);
        buy2 = Math.max(buy2, sell1 - p);
        sell2 = Math.max(sell2, buy2 + p);
    }
    return sell2;
}

Explanation

  1. buy1 = max(buy1, -p)
  2. sell1 = max(sell1, buy1 + p)
  3. buy2 = max(buy2, sell1 - p)
  4. sell2 = max(sell2, buy2 + p)

Problem 440: Best Time to Buy and Sell Stock IVhard

Question Statement

At most k transactions.

Input: k=2, prices=[2,4,1]
Output:
2

Brute force

Recursion over day, holding state and remaining transactions.

Optimized idea

DP with buy[t] and sell[t] for each transaction count.

Why it works

Generalizes the two-transaction solution to k.

Java implementation

public static int maxProfitIV(int k, int[] prices) {
    int n = prices.length;
    if (n < 2) return 0;
    if (k >= n / 2) {
        int profit = 0;
        for (int i = 1; i < n; i++) if (prices[i] > prices[i - 1]) profit += prices[i] - prices[i - 1];
        return profit;
    }
    int[] buy = new int[k + 1], sell = new int[k + 1];
    Arrays.fill(buy, Integer.MIN_VALUE);
    for (int p : prices)
        for (int t = 1; t <= k; t++) {
            buy[t] = Math.max(buy[t], sell[t - 1] - p);
            sell[t] = Math.max(sell[t], buy[t] + p);
        }
    return sell[k];
}

Explanation

  1. If k >= n/2 use the unlimited solution
  2. buy[t] = max(buy[t], sell[t-1] - p)
  3. sell[t] = max(sell[t], buy[t] + p)

Problem 441: Matrix Chain Multiplicationhard

Question Statement

Min multiplications.

Input: arr=[10,20,30,40,50]
Output:
38000

Brute force

Recursion over all parenthesizations.

Optimized idea

Interval DP: try every split point.

Why it works

dp[i][j] = min over k of dp[i][k] + dp[k+1][j] + arr[i-1]*arr[k]*arr[j].

Java implementation

public static int matrixMultiplication(int[] arr) {
    int n = arr.length;
    int[][] dp = new int[n][n];
    for (int len = 2; len < n; len++)
        for (int i = 1; i + len - 1 < n; i++) {
            int j = i + len - 1;
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i; k < j; k++)
                dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k + 1][j] + arr[i - 1] * arr[k] * arr[j]);
        }
    return dp[1][n - 1];
}

Explanation

  1. dp[i][i] = 0
  2. For increasing lengths try each k
  3. Take the minimum cost

16

Problem 443: Burst Balloonshard

Question Statement

Max coins.

Input: nums=[3,1,5,8]
Output:
167

Brute force

Try all bursting orders.

Optimized idea

Interval DP choosing the last balloon to burst.

Why it works

The last balloon k in (i, j) has neighbours i and j, making subproblems independent.

Java implementation

public static int maxCoins(int[] nums) {
    int n = nums.length;
    int[] a = new int[n + 2];
    a[0] = a[n + 1] = 1;
    for (int i = 0; i < n; i++) a[i + 1] = nums[i];
    int[][] dp = new int[n + 2][n + 2];
    for (int len = 2; len <= n + 1; len++)
        for (int i = 0; i + len <= n + 1; i++) {

            for (int k = i + 1; k < j; k++)
                dp[i][j] = Math.max(dp[i][j], dp[i][k] + dp[k][j] + a[i] * a[k] * a[j]);
        }
    return dp[0][n + 1];
}

  1. Pad with 1 at both ends
  2. dp[i][j] = max over k of dp[i][k] + dp[k][j] + a[i]*a[k]*a[j]

Problem 444: Evaluate Boolean Expression to Truehard

Question Statement

Ways to parenthesize to true.

Input: exp="T or F and T"
Output:
2

Brute force

Enumerate all parenthesizations.

Optimized idea

Interval DP storing ways for true and false.

Why it works

For each operator split, combine left and right counts by the operator's truth table.

Java implementation

public static int evaluateExp(String exp) {
    String[] tok = exp.trim().split("\\s+");
    int n = (tok.length + 1) / 2;
    boolean[] v = new boolean[n];
    String[] op = new String[n - 1];
    for (int i = 0; i < n; i++) v[i] = tok[2 * i].equals("T");
    for (int i = 0; i + 1 < n; i++) op[i] = tok[2 * i + 1];
    long[][] T = new long[n][n], F = new long[n][n];
    for (int i = 0; i < n; i++) { T[i][i] = v[i] ? 1 : 0; F[i][i] = v[i] ? 0 : 1; }
    for (int len = 2; len <= n; len++)
        for (int i = 0; i + len <= n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                long lt = T[i][k], lf = F[i][k], rt = T[k + 1][j], rf = F[k + 1][j];
                long tot = (lt + lf) * (rt + rf);
                long t;
                switch (op[k]) {
                    case "and": t = lt * rt; break;
                    case "or": t = tot - lf * rf; break;
                    default: t = lt * rf + lf * rt;
                }
                T[i][j] += t;
                F[i][j] += tot - t;
            }
        }
    return (int) T[0][n - 1];
}

Explanation

  1. Parse operands and operators
  2. T[i][j], F[i][j] for each interval
  3. For each operator k combine counts
  4. Answer T[0][n-1]

Problem 445: Palindrome Partitioning IIhard

Question Statement

Min cuts.

Input: s="aab"
Output:
1

Brute force

Try all partitions recursively.

Optimized idea

Precompute palindromes then DP over cut counts.

Why it works

cuts[i] = min over palindromic suffixes of cuts[j] + 1.

Java implementation

public static int minCutPalindrome(String s) {
    int n = s.length();
    boolean[][] pal = new boolean[n][n];
    for (int i = n - 1; i >= 0; i--)
        for (int j = i; j < n; j++) pal[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 2 || pal[i + 1][j - 1]);
    int[] cuts = new int[n];
    for (int i = 0; i < n; i++) {
        if (pal[0][i]) { cuts[i] = 0; continue; }
        cuts[i] = Integer.MAX_VALUE;
        for (int j = 0; j < i; j++) if (pal[j + 1][i]) cuts[i] = Math.min(cuts[i], cuts[j] + 1);
    }
    return cuts[n - 1];
}

Explanation

  1. pal[i][j] table
  2. cuts[i] = 0 if s[0..i] is a palindrome
  3. Otherwise min cuts[j] + 1 over palindromic s[j+1..i]

Problem 446: Partition Array for Maximum Sumhard

Question Statement

Subarrays up to size k.

Input: arr=[1,15,7,9,2,5,10], k=3
Output:
84

Brute force

Recursion over every partition.

Optimized idea

DP: dp[i] = best using the last len <= k elements as one partition.

Why it works

Each partition becomes the maximum of the block times its length.

Java implementation

public static int maxSumAfterPartitioning(int[] arr, int k) {
    int n = arr.length;
    int[] dp = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        int max = 0;
        for (int len = 1; len <= k && i - len >= 0; len++) {
            max = Math.max(max, arr[i - len]);
            dp[i] = Math.max(dp[i], dp[i - len] + max * len);
        }
    }
    return dp[n];
}

Explanation

  1. For each i try block lengths 1..k
  2. Track the max in the block
  3. dp[i] = max(dp[i - len] + max * len)

Problem 447: Maximum Rectangle Area with All 1shard

Question Statement

Largest rectangle of 1s.

Input: matrix=[[1,0,1],[1,1,1]]
Output:
3

Brute force

Check every rectangle.

Optimized idea

Histogram per row plus the largest rectangle in a histogram.

Why it works

Each row's column heights form a histogram.

Java implementation

public static int maximalRectangleDP(int[][] matrix) {
    int n = matrix[0].length, best = 0;
    int[] h = new int[n];
    for (int[] row : matrix) {
        for (int j = 0; j < n; j++) h[j] = row[j] == 1 ? h[j] + 1 : 0;
        Deque<Integer> st = new ArrayDeque<>();
        for (int i = 0; i <= n; i++) {
            int cur = i == n ? 0 : h[i];
            while (!st.isEmpty() && h[st.peek()] > cur) {
                int height = h[st.pop()];
                int w = st.isEmpty() ? i : i - st.peek() - 1;
                best = Math.max(best, height * w);
            }
            st.push(i);
        }
    }
    return best;
}

Explanation

  1. heights[j] = consecutive ones
  2. Largest rectangle with a stack
  3. Track the best per row

Problem 448: Count Square Submatrices with All 1shard

Question Statement

Count squares.

Input: matrix=[[0,1,1,1],[1,1,1,1],[0,1,1,1]]
Output:
15

Brute force

Check each square at every cell.

Optimized idea

DP: dp[i][j] = 1 + min of the three neighbours.

Why it works

dp[i][j] is both the largest square side and the count of squares ending there.

Java implementation

public static int countSquares(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length, total = 0;
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (matrix[i - 1][j - 1] == 1) {
                dp[i][j] = 1 + Math.min(dp[i - 1][j], Math.min(dp[i][j - 1], dp[i - 1][j - 1]));
                total += dp[i][j];
            }
    return total;
}

Explanation

  1. For '1' cells compute dp
  2. Sum all dp values
