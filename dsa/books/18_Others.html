Problem 464: Majority Element (Moore Voting)easy

Question Statement

Boyer-Moore.

Input: arr=[2,2,1,1,1,2,2]
Output:
2

Brute force

Count each element with a map.

Optimized idea

Boyer-Moore voting.

Why it works

The majority element survives cancellation against all other elements.

Java implementation

public static int majorityMoore(int[] arr) {
    int cand = 0, count = 0;
    for (int x : arr) {
        if (count == 0) cand = x;
        count += x == cand ? 1 : -1;
    }
    return cand;
}

Explanation

  1. Candidate and count
  2. If count == 0 take the current element
  3. Same increments, different decrements

Problem 465: Kth Smallest in Sorted Matrixmedium

Question Statement

K-th smallest.

Input: matrix=[[1,5,9],[10,11,13],[12,13,15]], k=8
Output:
13

Brute force

Flatten and sort.

Optimized idea

Binary search on the value using row/column sorted counting.

Why it works

Counting elements <= mid is O(n) with the staircase walk, so the search is O(n log range).

Java implementation

public static int kthSmallestMatrix(int[][] matrix, int k) {
    int n = matrix.length, lo = matrix[0][0], hi = matrix[n - 1][n - 1];
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2, cnt = 0, j = n - 1;
        for (int i = 0; i < n; i++) {
            while (j >= 0 && matrix[i][j] > mid) j--;
            cnt += j + 1;
        }
        if (cnt < k) lo = mid + 1; else hi = mid;
    }
    return lo;
}

Explanation

  1. lo = top-left, hi = bottom-right
  2. Count elements <= mid
  3. If count < k move lo else hi

Problem 466: Pow(x, n)medium

Question Statement

x raised to n.

Input: x=2.0, n=10
Output:
1024.0

Brute force

Multiply x, n times.

Optimized idea

Fast exponentiation by squaring.

Why it works

Halving the exponent each step gives O(log n).

Java implementation

public static double myPow(double x, int n) {
    long e = n;
    if (e < 0) { x = 1 / x; e = -e; }
    double res = 1;
    while (e > 0) {
        if ((e & 1) == 1) res *= x;
        x *= x;
        e >>= 1;
    }
    return res;
}

Explanation

  1. Use long to handle Integer.MIN_VALUE
  2. If n < 0 invert x
  3. Square x and halve n, multiplying when n is odd

Problem 467: Excel Sheet Column Numbermedium

Question Statement

Column title to number.

Input: col="AB"
Output:
28

Brute force

Enumerate titles until the match.

Optimized idea

Treat the title as a base-26 number.

Why it works

Each letter is a digit 1..26.

Java implementation

public static int titleToNumber(String col) {
    int res = 0;
    for (char c : col.toCharArray()) res = res * 26 + (c - 'A' + 1);
    return res;
}

Explanation

  1. res = 0
  2. For each char res = res * 26 + (c - 'A' + 1)

Problem 468: Gray Codemedium

Question Statement

n-bit Gray code.

Input: n=2
Output:
[0,1,3,2]

Brute force

Build by backtracking and check one-bit differences.

Optimized idea

Formula i ^ (i >> 1).

Why it works

Adjacent integers differ in a single bit after this transform.

Java implementation

public static List<Integer> grayCode(int n) {
    List<Integer> res = new ArrayList<>();
    for (int i = 0; i < (1 << n); i++) res.add(i ^ (i >> 1));
    return res;
}

Explanation

  1. For i in 0..2^n-1
  2. Add i ^ (i >> 1)

Problem 469: Valid Sudokumedium

Question Statement

Check board validity.

Input: 9x9 board
Output:
true

Brute force

Recheck rows, columns and boxes separately.

Optimized idea

One pass with row, column and box sets.

Why it works

A repeated digit in any of the three groups invalidates the board.

Java implementation

public static boolean isValidSudoku(char[][] board) {
    Set<String> seen = new HashSet<>();
    for (int i = 0; i < 9; i++)
        for (int j = 0; j < 9; j++) {
            char c = board[i][j];
            if (c == '.') continue;
            if (!seen.add(c + " in row " + i) || !seen.add(c + " in col " + j) || !seen.add(c + " in box " + i / 3 + "-" + j / 3))
                return false;
        }
    return true;
}

Explanation

  1. Skip '.'
  2. Build keys for row, column and box
  3. If a key is already seen return false

Problem 470: Spiral Matrix IImedium

Question Statement

Generate spiral matrix.

Input: n=3
Output:
[[1,2,3],[8,9,4],[7,6,5]]

Brute force

Fill with a direction array and visited matrix.

Optimized idea

Shrinking boundaries, same as spiral traversal.

Why it works

Each layer is filled once in four passes.

Java implementation

public static int[][] generateMatrix(int n) {
    int[][] m = new int[n][n];
    int t = 0, b = n - 1, l = 0, r = n - 1, v = 1;
    while (t <= b && l <= r) {
        for (int j = l; j <= r; j++) m[t][j] = v++;
        t++;
        for (int i = t; i <= b; i++) m[i][r] = v++;
        r--;
        for (int j = r; j >= l && t <= b; j--) m[b][j] = v++;
        b--;
        for (int i = b; i >= t && l <= r; i--) m[i][l] = v++;
        l++;
    }
    return m;
}

Explanation

  1. top, bottom, left, right
  2. Fill right, down, left, up
  3. Move the boundaries inward

Problem 471: Product of Array Except Selfmedium

Question Statement

Product of others without division.

Input: arr=[1,2,3,4]
Output:
[24,12,8,6]

Brute force

For each index multiply all others, O(n^2).

Optimized idea

Prefix product pass then suffix product pass.

Why it works

Product except self = product of everything before times everything after.

Java implementation

public static int[] productExceptSelf(int[] arr) {
    int n = arr.length;
    int[] res = new int[n];
    res[0] = 1;
    for (int i = 1; i < n; i++) res[i] = res[i - 1] * arr[i - 1];
    int suffix = 1;
    for (int i = n - 1; i >= 0; i--) {
        res[i] *= suffix;
        suffix *= arr[i];
    }
    return res;
}

Explanation

  1. res[i] = product of prefix
  2. Walk from the right with a running suffix product
  3. Multiply into res

Problem 472: Container With Most Watermedium

Question Statement

Max water area.

Input: height=[1,8,6,2,5,4,8,3,7]
Output:
49

Brute force

Check every pair of lines.

Optimized idea

Two pointers moving the shorter line inward.

Why it works

The width shrinks every step, so only a taller line can improve the area.

Java implementation

public static int maxArea(int[] height) {
    int l = 0, r = height.length - 1, best = 0;
    while (l < r) {
        best = Math.max(best, Math.min(height[l], height[r]) * (r - l));
        if (height[l] < height[r]) l++; else r--;
    }
    return best;
}

Explanation

  1. l = 0, r = n-1
  2. area = min(h[l], h[r]) * (r - l)
  3. Move the pointer at the shorter line

Problem 473: Minimum Number of Jumps to Reach Endmedium

Question Statement

Min jumps.

Input: arr=[2,3,1,1,4]
Output:
2

Brute force

BFS/DP over all jumps, O(n^2).

Optimized idea

Greedy window with the current end and farthest reach.

Why it works

Each time the current range ends we must jump once more to the farthest reachable position.

Java implementation

public static int minJumpsToEnd(int[] arr) {
    int n = arr.length, jumps = 0, end = 0, far = 0;
    for (int i = 0; i < n - 1; i++) {
        far = Math.max(far, i + arr[i]);
        if (i == end) {
            if (far <= i) return -1;
            jumps++;
            end = far;
        }
    }
    return jumps;
}

Explanation

  1. jumps = 0, end = 0, far = 0
  2. far = max(far, i + arr[i])
  3. When i == end jumps++, end = far
  4. Return -1 if far cannot advance

Problem 474: Boyer-Moore Majority Vote Generalizedmedium

Question Statement

Elements > n/k times.

Input: arr=[3,1,2,2,1,2,3,3], k=4
Output:
[2,3]

Brute force

Count every element with a map and filter.

Optimized idea

Generalized Boyer-Moore with k-1 candidates, then verify.

Why it works

At most k-1 values can occur more than n/k times.

Java implementation

public static List<Integer> majorityKth(int[] arr, int k) {
    Map<Integer, Integer> cand = new HashMap<>();
    for (int x : arr) {
        if (cand.containsKey(x)) cand.merge(x, 1, Integer::sum);
        else if (cand.size() < k - 1) cand.put(x, 1);
        else {
            Iterator<Map.Entry<Integer, Integer>> it = cand.entrySet().iterator();
            while (it.hasNext()) {
                Map.Entry<Integer, Integer> e = it.next();
                if (e.getValue() == 1) it.remove(); else e.setValue(e.getValue() - 1);
            }
        }
    }
    Map<Integer, Integer> cnt = new HashMap<>();
    for (int x : arr) if (cand.containsKey(x)) cnt.merge(x, 1, Integer::sum);
    List<Integer> res = new ArrayList<>();
    for (Map.Entry<Integer, Integer> e : cnt.entrySet()) if (e.getValue() > arr.length / k) res.add(e.getKey());
    Collections.sort(res);
    return res;
}

Explanation

  1. Keep up to k-1 candidate counts
  2. Decrement all when full and the new value is not a candidate
  3. Recount candidates and keep those above n/k

Problem 475: Median in a Row-wise Sorted Matrixhard

Question Statement

Median.

Input: matrix=[[1,3,5],[2,6,9],[3,6,9]]
Output:
5

Brute force

Flatten, sort and take the middle.

Optimized idea

Binary search on the value with a per-row upper bound.

Why it works

The median is the smallest value with at least (n*m+1)/2 elements <= it.

Java implementation

public static int medianRowWise(int[][] matrix) {
    int n = matrix.length, m = matrix[0].length, lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;
    for (int[] r : matrix) { lo = Math.min(lo, r[0]); hi = Math.max(hi, r[m - 1]); }
    int need = (n * m + 1) / 2;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2, cnt = 0;
        for (int[] r : matrix) {
            int l = 0, h = m;
            while (l < h) { int x = (l + h) / 2; if (r[x] <= mid) l = x + 1; else h = x; }
            cnt += l;
        }
        if (cnt < need) lo = mid + 1; else hi = mid;
    }
    return lo;
}

Explanation

  1. lo = min of first column, hi = max of last column
  2. Count elements <= mid in each row by binary search
  3. Adjust the range

Problem 476: Minimum Cost to Reach Destination via Bitmaskhard

Question Statement

Travelling salesman via bitmask DP.

Input: dist=[[0,10,15],[10,0,20],[15,20,0]]
Output:
45

Brute force

Try all n! city orders.

Optimized idea

Bitmask DP: dp[mask][i] = cheapest way to visit mask ending at i.

Why it works

Subproblems are shared, giving O(n^2 * 2^n).

Java implementation

public static int tspBitmask(int[][] dist) {
    int n = dist.length, INF = Integer.MAX_VALUE / 2;
    int[][] dp = new int[1 << n][n];
    for (int[] r : dp) Arrays.fill(r, INF);
    dp[1][0] = 0;
    for (int mask = 1; mask < (1 << n); mask++)
        for (int i = 0; i < n; i++) {
            if (dp[mask][i] >= INF || (mask & (1 << i)) == 0) continue;
            for (int j = 0; j < n; j++) {
                if ((mask & (1 << j)) != 0) continue;
                int nm = mask | (1 << j);
                dp[nm][j] = Math.min(dp[nm][j], dp[mask][i] + dist[i][j]);
            }
        }
    int best = INF;
    for (int i = 1; i < n; i++) best = Math.min(best, dp[(1 << n) - 1][i] + dist[i][0]);
    return best;
}

Explanation

  1. dp[1][0] = 0
  2. For each mask and last city i try each unvisited j
  3. dp[mask
  4. 1<<j][j] = min(dp[mask][i] + dist[i][j])
  5. Close the tour back to city 0
