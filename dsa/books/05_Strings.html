Problem 128: Remove Outermost Parentheseseasy

Question Statement

Strip outer parens of each primitive.

Input: s="(()())(())"
Output:
"()()()"

Brute force

Decompose into primitives and rebuild each without its outer pair.

Optimized idea

Track depth; append a char only if it is not an outer parenthesis.

Why it works

Outer '(' is at depth 0 before increment and outer ')' at depth 0 after decrement.

Java implementation

public static String removeOuterParentheses(String s) {
    StringBuilder sb = new StringBuilder();
    int depth = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') { if (depth++ > 0) sb.append(c); }
        else { if (--depth > 0) sb.append(c); }
    }
    return sb.toString();
}

Explanation

  1. depth = 0
  2. For '(' append if depth > 0 then depth++
  3. For ')' depth-- then append if depth > 0

Problem 129: Reverse Words in a Stringeasy

Question Statement

Reverse the order of words.

Input: s="the sky is blue"
Output:
"blue is sky the"

Brute force

Split on spaces and reverse with a list.

Optimized idea

Scan from the end and collect words.

Why it works

Skipping spaces handles leading, trailing and repeated spaces.

Java implementation

public static String reverseWords(String s) {
    String[] w = s.trim().split("\\s+");
    StringBuilder sb = new StringBuilder();
    for (int i = w.length - 1; i >= 0; i--) {
        sb.append(w[i]);
        if (i > 0) sb.append(' ');
    }
    return sb.toString();
}

Explanation

  1. Trim and split on whitespace
  2. Append from the last word to the first
  3. Join with single spaces

Problem 130: Largest Odd Number in Stringeasy

Question Statement

Largest odd-valued substring.

Input: num="35427"
Output:
"35427"

Brute force

Check every substring for oddness.

Optimized idea

Scan from the right for the first odd digit.

Why it works

Oddness depends only on the last digit; the longest prefix ends at the last odd digit.

Java implementation

public static String largestOddNumber(String num) {
    for (int i = num.length() - 1; i >= 0; i--)
        if ((num.charAt(i) - '0') % 2 == 1) return num.substring(0, i + 1);
    return "";
}

Explanation

  1. Loop i from the end
  2. Stop at the first odd digit
  3. Return the prefix up to i

Problem 131: Longest Common Prefixeasy

Question Statement

Longest common prefix.

Input: strs=["flower","flow","flight"]
Output:
"fl"

Brute force

Test every prefix of the first string against all others.

Optimized idea

Sort and compare first and last strings, or shrink a prefix.

Why it works

Extremes in lexicographic order share the common prefix of everything between them.

Java implementation

public static String longestCommonPrefix(String[] strs) {
    String p = strs[0];
    for (String s : strs) while (!s.startsWith(p)) p = p.substring(0, p.length() - 1);
    return p;
}

Explanation

  1. prefix = strs[0]
  2. While a string does not start with prefix, shorten it
  3. Return prefix

Problem 132: Isomorphic Stringseasy

Question Statement

Check if one-to-one char mapping exists.

Input: s="egg", t="add"
Output:
true

Brute force

Try all mappings.

Optimized idea

Map each character to its last seen index in both strings.

Why it works

Equal last-seen positions at each step mean the mapping is consistent and one-to-one.

Java implementation

public static boolean isIsomorphic(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] a = new int[256], b = new int[256];
    for (int i = 0; i < s.length(); i++) {
        if (a[s.charAt(i)] != b[t.charAt(i)]) return false;
        a[s.charAt(i)] = b[t.charAt(i)] = i + 1;
    }
    return true;
}

Explanation

  1. Two arrays of size 256
  2. For each i compare stored positions
  3. Update both with i+1

Problem 133: Check if One String is Rotation of Anothereasy

Question Statement

True if s can become goal by rotations.

Input: s="abcde", goal="cdeab"
Output:
true

Brute force

Try every rotation.

Optimized idea

Check if goal is a substring of s + s.

Why it works

Every rotation of s appears inside s concatenated with itself.

Java implementation

public static boolean isRotation(String s, String goal) {
    return s.length() == goal.length() && (s + s).contains(goal);
}

Explanation

  1. Lengths must match
  2. Build s+s
  3. Check contains(goal)

Problem 134: Valid Anagrameasy

Question Statement

True if t is an anagram of s.

Input: s="anagram", t="nagaram"
Output:
true

Brute force

Sort both strings and compare.

Optimized idea

Count letters in one array.

Why it works

Anagrams have identical letter counts.

Java implementation

public static boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] c = new int[26];
    for (int i = 0; i < s.length(); i++) { c[s.charAt(i) - 'a']++; c[t.charAt(i) - 'a']--; }
    for (int x : c) if (x != 0) return false;
    return true;
}

Explanation

  1. Equal lengths required
  2. Increment for s and decrement for t
  3. All counts must be zero

Problem 135: Maximum Nesting Depth of Parentheseseasy

Question Statement

Max nesting depth.

Input: s="(1+(2*3)+((8)/4))+1"
Output:
3

Brute force

Use a stack to track open parentheses.

Optimized idea

A single counter of open brackets.

Why it works

Stack size equals the current depth, so a counter is enough.

Java implementation

public static int maxDepth(String s) {
    int d = 0, max = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') max = Math.max(max, ++d);
        else if (c == ')') d--;
    }
    return max;
}

Explanation

  1. depth = max = 0
  2. '(' increments and updates max
  3. ')' decrements

Problem 136: Roman to Integereasy

Question Statement

Convert roman numeral.

Input: s="MCMXCIV"
Output:
1994

Brute force

Match fixed patterns with many ifs.

Optimized idea

Map symbols to values; subtract when the next is larger.

Why it works

Subtractive notation is exactly a smaller symbol before a larger one.

Java implementation

public static int romanToInt(String s) {
    Map<Character, Integer> m = Map.of('I', 1, 'V', 5, 'X', 10, 'L', 50, 'C', 100, 'D', 500, 'M', 1000);
    int total = 0;
    for (int i = 0; i < s.length(); i++) {
        int v = m.get(s.charAt(i));
        if (i + 1 < s.length() && v < m.get(s.charAt(i + 1))) total -= v; else total += v;
    }
    return total;
}

Explanation

  1. Value map
  2. Add value
  3. If next value is larger subtract instead

Problem 138: Sort Characters by Frequencymedium

Question Statement

Sort by decreasing frequency.

Input: s="tree"
Output:
"eert"

Brute force

Count frequencies then selection-sort characters.

Optimized idea

Frequency map and sort characters by count descending.

Why it works

Sorting distinct characters is cheaper than sorting the whole string.

Java implementation

public static String frequencySort(String s) {
    Map<Character, Integer> m = new HashMap<>();
    for (char c : s.toCharArray()) m.merge(c, 1, Integer::sum);
    List<Map.Entry<Character, Integer>> l = new ArrayList<>(m.entrySet());
    l.sort((a, b) -> b.getValue() - a.getValue());
    StringBuilder sb = new StringBuilder();
    for (Map.Entry<Character, Integer> e : l)
        for (int i = 0; i < e.getValue(); i++) sb.append(e.getKey());
    return sb.toString();
}

Explanation

  1. Count with a map
  2. Sort entries by count descending
  3. Repeat each char by its count

Problem 139: String to Integer (atoi)medium

Question Statement

Implement atoi with clamp.

Input: s=" -42"
Output:
-42

Brute force

Use library parsing with try/catch.

Optimized idea

Manual parse with sign, digits and overflow clamp.

Why it works

Clamping before overflow keeps results in int range.

Java implementation

public static int myAtoi(String s) {
    int i = 0, n = s.length(), sign = 1;
    while (i < n && s.charAt(i) == ' ') i++;
    if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) sign = s.charAt(i++) == '-' ? -1 : 1;
    long r = 0;
    while (i < n && Character.isDigit(s.charAt(i))) {
        r = r * 10 + (s.charAt(i++) - '0');
        if (r * sign > Integer.MAX_VALUE) return Integer.MAX_VALUE;
        if (r * sign < Integer.MIN_VALUE) return Integer.MIN_VALUE;
    }
    return (int) (r * sign);
}

Explanation

  1. Skip leading spaces
  2. Read optional sign
  3. Accumulate digits
  4. Clamp to int limits

Problem 140: Longest Palindromic Substringmedium

Question Statement

Longest palindromic substring.

Input: s="babad"
Output:
"bab"

Brute force

Check every substring for palindrome, O(n^3).

Optimized idea

Expand around each center.

Why it works

A palindrome mirrors around its center, giving O(n^2).

Java implementation

public static String longestPalindrome(String s) {
    int start = 0, best = 0;
    for (int c = 0; c < s.length(); c++) {
        for (int w = 0; w < 2; w++) {
            int l = c, r = c + w;
            while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
            if (r - l - 1 > best) { best = r - l - 1; start = l + 1; }
        }
    }
    return s.substring(start, start + best);
}

Explanation

  1. For each i try odd and even centers
  2. Expand while chars match
  3. Keep the longest

Problem 141: Sum of Beauty of All Substringsmedium

Question Statement

Beauty = max freq - min freq per substring.

Input: s="aabcb"
Output:
5

Brute force

Compute frequency of every substring from scratch.

Optimized idea

For each start extend the end while updating counts.

Why it works

Updating counts incrementally avoids recomputation, O(26 n^2).

Java implementation

public static int beautySum(String s) {
    int total = 0;
    for (int i = 0; i < s.length(); i++) {
        int[] f = new int[26];
        for (int j = i; j < s.length(); j++) {
            f[s.charAt(j) - 'a']++;
            int max = 0, min = Integer.MAX_VALUE;
            for (int x : f) if (x > 0) { max = Math.max(max, x); min = Math.min(min, x); }
            total += max - min;
        }
    }
    return total;
}

Explanation

  1. For each i reset counts
  2. Extend j and update count
  3. Beauty = max - min among non-zero counts

Problem 142: Reverse Every Word in a Stringmedium

Question Statement

Reverse letters in each word.

Input: s="Let's take LeetCode"
Output:
"s'teL ekat edoCteeL"

Brute force

Reverse the whole string and then reorder the words.

Optimized idea

Split by space and reverse each word.

Why it works

Reversing each word independently keeps the word order.

Java implementation

public static String reverseEachWord(String s) {
    String[] w = s.split(" ");
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < w.length; i++) {
        sb.append(new StringBuilder(w[i]).reverse());
        if (i + 1 < w.length) sb.append(' ');
    }
    return sb.toString();
}

Explanation

  1. Split on spaces
  2. Reverse every token with StringBuilder
  3. Join with spaces
