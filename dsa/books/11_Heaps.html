Problem 259: Introduction: Implement Min Heapeasy

Question Statement

Implement insert, extractMin, peek.

Input: insert 3,1,2 extractMin
Output:
1

Brute force

Keep an unsorted list and scan for the minimum.

Optimized idea

Array-based binary heap with sift up and sift down.

Why it works

The parent of i is (i-1)/2, so insert and extract are O(log n).

Java implementation

public static void minHeap() {
    class MinHeap {
        List<Integer> a = new ArrayList<>();
        void insert(int x) {
            a.add(x);
            int i = a.size() - 1;
            while (i > 0 && a.get((i - 1) / 2) > a.get(i)) { Collections.swap(a, i, (i - 1) / 2); i = (i - 1) / 2; }
        }
        int peek() { return a.get(0); }
        int extractMin() {
            int top = a.get(0);
            a.set(0, a.get(a.size() - 1));
            a.remove(a.size() - 1);
            int i = 0, n = a.size();
            while (true) {
                int l = 2 * i + 1, r = l + 1, m = i;
                if (l < n && a.get(l) < a.get(m)) m = l;
                if (r < n && a.get(r) < a.get(m)) m = r;
                if (m == i) break;
                Collections.swap(a, i, m);
                i = m;
            }
            return top;
        }
    }
    MinHeap h = new MinHeap();
    h.insert(3); h.insert(1); h.insert(2);
    System.out.println(h.extractMin());
}

Explanation

  1. insert: append then sift up
  2. extractMin: swap root with last, remove, sift down
  3. peek returns a[0]

Problem 261: Heapify and Build Heapeasy

Question Statement

Convert array into min heap.

Input: arr=[4,10,3,5,1]
Output:
[1,4,3,5,10]

Brute force

Insert elements one by one in O(n log n).

Optimized idea

Sift down every internal node from n/2-1 to 0.

Why it works

Most nodes are near the bottom so the total work is O(n).

Java implementation

public static void buildHeap(int[] arr) {
    int n = arr.length;
    for (int i = n / 2 - 1; i >= 0; i--) {
        int j = i;
        while (true) {
            int l = 2 * j + 1, r = l + 1, m = j;
            if (l < n && arr[l] < arr[m]) m = l;
            if (r < n && arr[r] < arr[m]) m = r;
            if (m == j) break;
            int t = arr[j]; arr[j] = arr[m]; arr[m] = t;
            j = m;
        }
    }
}

Explanation

  1. Start from the last parent
  2. Sift each node down
  3. Repeat up to the root

Problem 262: Heap Sorteasy

Question Statement

Sort using heap.

Input: arr=[4,1,3,9,7]
Output:
[1,3,4,7,9]

Brute force

Selection sort.

Optimized idea

Build a max heap then repeatedly move the max to the end.

Why it works

Each extraction costs O(log n), giving O(n log n) in place.

Java implementation

public static void heapSort(int[] arr) {
    int n = arr.length;
    for (int i = n / 2 - 1; i >= 0; i--) sift(arr, i, n);
    for (int end = n - 1; end > 0; end--) {
        int t = arr[0]; arr[0] = arr[end]; arr[end] = t;
        sift(arr, 0, end);
    }
}

private static void sift(int[] a, int i, int n) {
    while (true) {
        int l = 2 * i + 1, r = l + 1, m = i;
        if (l < n && a[l] > a[m]) m = l;
        if (r < n && a[r] > a[m]) m = r;
        if (m == i) return;
        int t = a[i]; a[i] = a[m]; a[m] = t;
        i = m;
    }
}

Explanation

  1. Build a max heap
  2. Swap root with the last unsorted item
  3. Sift down within the shrunken range

Problem 263: Check if Array Represents Min Heapeasy

Question Statement

Verify heap property.

Input: arr=[10,20,30,21,23]
Output:
true

Brute force

Build a heap and compare.

Optimized idea

Check each internal node against its children.

Why it works

Min-heap property: parent <= both children.

Java implementation

public static boolean isMinHeap(int[] arr) {
    int n = arr.length;
    for (int i = 0; i <= (n - 2) / 2; i++) {
        if (2 * i + 1 < n && arr[i] > arr[2 * i + 1]) return false;
        if (2 * i + 2 < n && arr[i] > arr[2 * i + 2]) return false;
    }
    return true;
}

Explanation

  1. For i in 0..n/2-1
  2. Compare with 2i+1 and 2i+2
  3. Return false on violation

Problem 264: Kth Largest Element in Arraymedium

Question Statement

K-th largest element.

Input: arr=[3,2,1,5,6,4], k=2
Output:
5

Brute force

Sort and take the k-th from the end.

Optimized idea

Min heap of size k.

Why it works

The heap keeps the k largest, and its root is the k-th largest.

Java implementation

public static int findKthLargest(int[] arr, int k) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int x : arr) {
        pq.add(x);
        if (pq.size() > k) pq.poll();
    }
    return pq.peek();
}

Explanation

  1. Push each element
  2. If size > k pop the smallest
  3. Return the root

Problem 266: Sort a K-Sorted Arraymedium

Question Statement

Each element at most k away from final position.

Input: arr=[6,5,3,2,8,10,9], k=3
Output:
[2,3,5,6,8,9,10]

Brute force

Sort the whole array in O(n log n).

Optimized idea

Min heap of size k+1.

Why it works

The smallest of the next k+1 elements is always the next output.

Java implementation

public static int[] sortKSorted(int[] arr, int k) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    int[] res = new int[arr.length];
    int idx = 0;
    for (int x : arr) {
        pq.add(x);
        if (pq.size() > k) res[idx++] = pq.poll();
    }
    while (!pq.isEmpty()) res[idx++] = pq.poll();
    return res;
}

Explanation

  1. Push the first k+1
  2. Poll the min and push the next element
  3. Drain at the end

Problem 267: Merge K Sorted Listsmedium

Question Statement

Merge k sorted lists.

Input: lists=[1->4->5,1->3->4,2->6]
Output:
1->1->2->3->4->4->5->6

Brute force

Collect all values, sort, rebuild.

Optimized idea

Min heap of the current heads of all lists.

Why it works

The smallest head is always the next node of the result.

Java implementation

public static Node mergeKLists(Node[] lists) {
    PriorityQueue<Node> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (Node n : lists) if (n != null) pq.add(n);
    Node d = new Node(0), t = d;
    while (!pq.isEmpty()) {
        Node n = pq.poll();
        t.next = n;
        t = n;
        if (n.next != null) pq.add(n.next);
    }
    return d.next;
}

Explanation

  1. Push all non-null heads
  2. Poll the smallest and attach
  3. Push its next

Problem 268: Replace Elements by Rankmedium

Question Statement

Replace each element with its rank.

Input: arr=[20,15,26,2,98,6]
Output:
[4,3,5,1,6,2]

Brute force

For each element count smaller distinct values.

Optimized idea

Sort a copy, assign ranks to distinct values, look up.

Why it works

Rank is the position among sorted distinct values.

Java implementation

public static int[] replaceByRank(int[] arr) {
    int[] s = arr.clone();
    Arrays.sort(s);
    Map<Integer, Integer> rank = new HashMap<>();
    for (int x : s) rank.putIfAbsent(x, rank.size() + 1);
    int[] res = new int[arr.length];
    for (int i = 0; i < arr.length; i++) res[i] = rank.get(arr[i]);
    return res;
}

Explanation

  1. Sort a copy
  2. Map each value to its rank
  3. Replace each element

Problem 269: Task Schedulermedium

Question Statement

Min time with cooldown n.

Input: tasks=[A,A,A,B,B,B], n=2
Output:
8

Brute force

Simulate time step by step with a heap.

Optimized idea

Formula based on the maximum frequency.

Why it works

The most frequent task forces (maxF-1) gaps of size n+1; ties fill the last row.

Java implementation

public static int leastInterval(char[] tasks, int n) {
    int[] f = new int[26];
    for (char c : tasks) f[c - 'A']++;
    int maxF = 0, cnt = 0;
    for (int x : f) maxF = Math.max(maxF, x);
    for (int x : f) if (x == maxF) cnt++;
    return Math.max(tasks.length, (maxF - 1) * (n + 1) + cnt);
}

Explanation

  1. Count frequencies
  2. maxF and how many tasks have it
  3. (maxF-1)*(n+1)+countMax
  4. At least tasks.length

Problem 270: Hands of Straightsmedium

Question Statement

Rearrange into consecutive groups.

Input: hand=[1,2,3,6,2,3,4,7,8], groupSize=3
Output:
true

Brute force

Try every grouping.

Optimized idea

Greedy from the smallest card using a TreeMap.

Why it works

The smallest remaining card must start a group.

Java implementation

public static boolean isNStraightHand(int[] hand, int groupSize) {
    if (hand.length % groupSize != 0) return false;
    TreeMap<Integer, Integer> m = new TreeMap<>();
    for (int x : hand) m.merge(x, 1, Integer::sum);
    while (!m.isEmpty()) {
        int first = m.firstKey();
        for (int i = 0; i < groupSize; i++) {
            Integer c = m.get(first + i);
            if (c == null) return false;
            if (c == 1) m.remove(first + i); else m.put(first + i, c - 1);
        }
    }
    return true;
}

Explanation

  1. If size % groupSize != 0 return false
  2. Count cards in a TreeMap
  3. Take the smallest card and remove a run of groupSize

Problem 271: Design Twittermedium

Question Statement

postTweet, follow, unfollow, getNewsFeed.

Input: postTweet(1,5) getNewsFeed(1)
Output:
[5]

Brute force

Store all tweets in one list and sort each time.

Optimized idea

Per-user tweet lists merged with a max heap by timestamp.

Why it works

The feed needs the 10 most recent from followees, a k-way merge.

Java implementation

public static void designTwitter() {
    class Twitter {
        int time = 0;
        Map<Integer, List<int[]>> tweets = new HashMap<>();
        Map<Integer, Set<Integer>> follows = new HashMap<>();
        void postTweet(int u, int id) { tweets.computeIfAbsent(u, x -> new ArrayList<>()).add(new int[]{time++, id}); }
        void follow(int a, int b) { follows.computeIfAbsent(a, x -> new HashSet<>()).add(b); }
        void unfollow(int a, int b) { if (follows.containsKey(a)) follows.get(a).remove(b); }
        List<Integer> getNewsFeed(int u) {
            PriorityQueue<int[]> pq = new PriorityQueue<>((x, y) -> y[0] - x[0]);
            Set<Integer> users = new HashSet<>(follows.getOrDefault(u, new HashSet<>()));
            users.add(u);
            for (int v : users) for (int[] t : tweets.getOrDefault(v, new ArrayList<>())) pq.add(t);
            List<Integer> res = new ArrayList<>();
            while (!pq.isEmpty() && res.size() < 10) res.add(pq.poll()[1]);
            return res;
        }
    }
    Twitter t = new Twitter();
    t.postTweet(1, 5);
    System.out.println(t.getNewsFeed(1));
}

Explanation

  1. postTweet stores (time, id)
  2. follow/unfollow modify sets
  3. getNewsFeed pushes latest of each followee into a heap and pops 10

Problem 272: Connect N Ropes with Minimum Costmedium

Question Statement

Min cost to connect ropes.

Input: ropes=[4,3,2,6]
Output:
29

Brute force

Try all merge orders.

Optimized idea

Greedy: always merge the two shortest ropes with a min heap.

Why it works

Smaller ropes are paid for more times if merged late, so merge them first.

Java implementation

public static int minCostRopes(int[] ropes) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int r : ropes) pq.add(r);
    int cost = 0;
    while (pq.size() > 1) {
        int s = pq.poll() + pq.poll();
        cost += s;
        pq.add(s);
    }
    return cost;
}

Explanation

  1. Push all ropes
  2. Pop two and add their sum to cost
  3. Push the sum back until one rope remains

Problem 273: Kth Largest Element in a Streamhard

Question Statement

Maintain k-th largest as stream.

Input: k=3, add(4) add(5) add(8) add(2)
Output:
4

Brute force

Sort after every add.

Optimized idea

Min heap of size k.

Why it works

The root is always the k-th largest seen so far.

Java implementation

public static void kthLargestStream() {
    class KthLargest {
        int k;
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        KthLargest(int k) { this.k = k; }
        int add(int x) {
            pq.add(x);
            if (pq.size() > k) pq.poll();
            return pq.peek();
        }
    }
    KthLargest s = new KthLargest(3);
    for (int x : new int[]{4, 5, 8, 2}) System.out.println(s.add(x));
}

Explanation

  1. Keep the k largest values
  2. add: push and pop if size > k
  3. Return the root

Problem 274: Maximum Sum Combinationhard

Question Statement

Top k sums a[i]+b[j].

Input: a=[1,4,2,3], b=[2,5,1,6], k=4
Output:
[10,9,9,8]

Brute force

Compute all n*n sums and sort.

Optimized idea

Sort both descending and use a max heap with a visited set.

Why it works

The next largest sum is always adjacent to a previously chosen pair.

Java implementation

public static int[] maxSumCombination(int[] a, int[] b, int k) {
    int n = a.length;
    Integer[] x = new Integer[n], y = new Integer[n];
    for (int i = 0; i < n; i++) { x[i] = a[i]; y[i] = b[i]; }
    Arrays.sort(x, Collections.reverseOrder());
    Arrays.sort(y, Collections.reverseOrder());
    PriorityQueue<int[]> pq = new PriorityQueue<>((p, q) -> q[0] - p[0]);
    Set<Long> seen = new HashSet<>();
    pq.add(new int[]{x[0] + y[0], 0, 0});
    seen.add(0L);
    int[] res = new int[k];
    for (int t = 0; t < k; t++) {
        int[] cur = pq.poll();
        res[t] = cur[0];
        int i = cur[1], j = cur[2];
        if (i + 1 < n && seen.add((long) (i + 1) * n + j)) pq.add(new int[]{x[i + 1] + y[j], i + 1, j});
        if (j + 1 < n && seen.add((long) i * n + j + 1)) pq.add(new int[]{x[i] + y[j + 1], i, j + 1});
    }
    return res;
}

Explanation

  1. Sort descending
  2. Push (a[0]+b[0], 0, 0)
  3. Pop and push (i+1,j) and (i,j+1) if unseen
  4. Repeat k times

Problem 275: Find Median from Data Streamhard

Question Statement

addNum, findMedian.

Input: add(1) add(2) findMedian() add(3) findMedian()
Output:
1.5, 2

Brute force

Sort after every insertion and take the middle.

Optimized idea

Two heaps: max heap for the lower half, min heap for the upper half.

Why it works

Heap tops are the middle elements; sizes differ by at most one.

Java implementation

public static void medianFinder() {
    class MedianFinder {
        PriorityQueue<Integer> lo = new PriorityQueue<>(Collections.reverseOrder()), hi = new PriorityQueue<>();
        void addNum(int x) {
            lo.add(x);
            hi.add(lo.poll());
            if (hi.size() > lo.size()) lo.add(hi.poll());
        }
        double findMedian() {
            return lo.size() > hi.size() ? lo.peek() : (lo.peek() + hi.peek()) / 2.0;
        }
    }
    MedianFinder m = new MedianFinder();
    m.addNum(1); m.addNum(2);
    System.out.println(m.findMedian());
    m.addNum(3);
    System.out.println(m.findMedian());
}

Explanation

  1. Add to the max heap then move its top to the min heap
  2. Rebalance so low has >= high
  3. Median is the top or the average of both tops

Problem 276: K Most Frequent Elementshard

Question Statement

Top k frequent elements.

Input: arr=[1,1,1,2,2,3], k=2
Output:
[1,2]

Brute force

Count frequencies and sort all entries.

Optimized idea

Frequency map plus a min heap of size k.

Why it works

The heap keeps the k highest frequencies in O(n log k).

Java implementation

public static int[] topKFrequent(int[] arr, int k) {
    Map<Integer, Integer> m = new HashMap<>();
    for (int x : arr) m.merge(x, 1, Integer::sum);
    PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> m.get(a) - m.get(b));
    for (int key : m.keySet()) {
        pq.add(key);
        if (pq.size() > k) pq.poll();
    }
    int[] res = new int[k];
    for (int i = k - 1; i >= 0; i--) res[i] = pq.poll();
    return res;
}

Explanation

  1. Count frequencies
  2. Push entries into a min heap by count
  3. Pop when size > k
  4. Collect the heap
