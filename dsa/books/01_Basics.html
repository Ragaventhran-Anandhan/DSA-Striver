Problem 1: Pattern 1 - Square of starseasy

Question Statement

Print an n x n square of stars.

Input: n=3
Output:
***
***
***

Brute force

Print stars with nested loops, row by row.

Optimized idea

Same nested loops; n rows, each with n stars, is already optimal for output size.

Why it works

Output has n*n characters, so O(n^2) is the minimum.

Java implementation

public static void pattern1(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) System.out.print("*");
        System.out.println();
    }
}

Explanation

  1. Loop i over rows
  2. Loop j over columns and print *
  3. Print a newline after each row

Problem 11: Pattern 11 - Binary triangleeasy

Question Statement

Alternating 1/0 starting with 1 each row.

Input: n=3
Output:
1
01
101

Brute force

Build a string per row using a toggle flag.

Optimized idea

Start value is 1 for even rows (0-indexed) and 0 for odd; flip each column.

Why it works

Parity of row index decides the first bit, XOR 1 flips it every step.

Java implementation

public static void pattern11(int n) {
    int start = 1;
    for (int i = 0; i < n; i++) {
        int bit = start;
        for (int j = 0; j <= i; j++) {
            System.out.print(bit);
            bit ^= 1;
        }
        start ^= 1;
        System.out.println();
    }
}

Explanation

  1. start = 1 for first row, flipped each row
  2. Inner loop prints current bit
  3. Flip bit after each print

Problem 19: Pattern 19 - Hollow butterflyeasy

Question Statement

Stars with a hollow gap forming a butterfly.

Input: n=3
Output:
**    **
**    **

Brute force

Hard-code the shapes.

Optimized idea

Upper and lower halves with border stars only; spaces fill the gap.

Why it works

Left wing, gap and right wing are independent, symmetric segments.

Java implementation

public static void pattern19(int n) {
    for (int r = 1; r <= 2 * n - 1; r++) {
        int k = r <= n ? r : 2 * n - r;
        for (int j = 1; j <= k; j++) System.out.print(j == 1 || j == k ? "*" : " ");
        for (int j = 0; j < 2 * (n - k); j++) System.out.print(" ");
        for (int j = 1; j <= k; j++) System.out.print(j == 1 || j == k ? "*" : " ");
        System.out.println();
    }
}

Explanation

  1. For each of 2n-1 rows compute k = row size
  2. Print wing borders only
  3. Gap is 2*(n-k) spaces

Problem 22: Pattern 22 - Concentric numberseasy

Question Statement

Concentric squares, outer value n down to 1.

Input: n=3
Output:
33333
32223
32123
32223
33333

Brute force

Build layers one by one in a 2D array.

Optimized idea

Value at (i,j) = n - min(i, j, size-1-i, size-1-j) with size = 2n-1.

Why it works

Distance to the nearest edge gives the ring number directly.

Java implementation

public static void pattern22(int n) {
    int size = 2 * n - 1;
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size; j++) {
            int d = Math.min(Math.min(i, j), Math.min(size - 1 - i, size - 1 - j));
            System.out.print(n - d);
        }
        System.out.println();
    }
}

Explanation

  1. size = 2n-1
  2. For each cell find the minimum distance to any border
  3. Print n minus that distance

Optimized idea

Problem 25: Check Palindrome Numbereasy

Question Statement

True if number reads same backwards.

Input: n=121
Output:
true

Brute force

Convert to string and compare with its reverse.

Optimized idea

Reverse the number mathematically and compare.

Why it works

A palindrome equals its own reverse.

Java implementation

public static boolean isPalindrome(int n) {
    if (n < 0) return false;
    int rev = 0, t = n;
    while (t > 0) { rev = rev * 10 + t % 10; t /= 10; }
    return rev == n;
}

  3. Compare with the original

Problem 26: GCD / HCFeasy

Question Statement

Greatest common divisor.

Input: a=20, b=15
Output:
5

Brute force

Try every number from min(a,b) down to 1.

Optimized idea

Euclid: gcd(a, b) = gcd(b, a % b).

Why it works

Common divisors of a and b are the same as those of b and a mod b.

Java implementation

public static int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

Explanation

  1. While b != 0
  2. Replace (a, b) with (b, a % b)
  3. Return a

Problem 27: Armstrong Numbereasy

Question Statement

Sum of digits raised to digit-count equals n.

Input: n=153
Output:
true

Brute force

Convert to string and use Math.pow per digit.

Optimized idea

Count digits then sum digit^count by integer multiplication.

Why it works

Armstrong definition is exactly that sum.

Java implementation

public static boolean isArmstrong(int n) {
    int k = String.valueOf(n).length(), sum = 0, t = n;
    while (t > 0) {
        int d = t % 10, p = 1;
        for (int i = 0; i < k; i++) p *= d;
        sum += p;
        t /= 10;
    }
    return sum == n;
}

Explanation

  1. Count digits k
  2. Sum each digit raised to k
  3. Compare with n

Problem 28: Print All Divisorseasy

Question Statement

Return all divisors in ascending order.

Input: n=36
Output:
[1,2,3,4,6,9,12,18,36]

Brute force

Check every i from 1 to n.

Optimized idea

Check i up to sqrt(n); each i gives divisors i and n/i.

Why it works

Divisors come in pairs around sqrt(n).

Java implementation

public static List<Integer> divisors(int n) {
    List<Integer> small = new ArrayList<>(), large = new ArrayList<>();
    for (int i = 1; (long) i * i <= n; i++) {
        if (n % i == 0) {
            small.add(i);
            if (i != n / i) large.add(n / i);
        }
    }
    Collections.reverse(large);
    small.addAll(large);
    return small;
}

Explanation

  1. Loop i while i*i <= n
  2. If i divides n add i to the front list
  3. Add n/i to the back list if different
  4. Join front and reversed back

Problem 31: Count Primes up to N (Sieve)easy

Question Statement

Number of primes strictly less than n.

Input: n=10
Output:
4

Brute force

Run isPrime on every number below n.

Optimized idea

Sieve of Eratosthenes.

Why it works

Marking multiples of each prime removes all composites in O(n log log n).

Java implementation

public static int countPrimes(int n) {
    if (n < 3) return 0;
    boolean[] comp = new boolean[n];
    int count = 0;
    for (int i = 2; i < n; i++) {
        if (!comp[i]) {
            count++;
            for (long j = (long) i * i; j < n; j += i) comp[(int) j] = true;
        }
    }
    return count;
}

Explanation

  1. Boolean array initialised to prime
  2. For each prime p, mark p*p, p*p+p, ... composite
  3. Count unmarked numbers from 2 to n-1

Problem 32: LCM of Two Numberseasy

Question Statement

Least common multiple.

Input: a=4, b=6
Output:
12

Brute force

Test multiples of the larger number until divisible by the other.

Optimized idea

lcm = a / gcd * b.

Why it works

gcd(a,b) * lcm(a,b) = a * b.

Java implementation

public static int lcm(int a, int b) {
    int x = a, y = b;
    while (y != 0) { int t = x % y; x = y; y = t; }
    return a / x * b;
}

Explanation

  1. Compute gcd with Euclid
  2. Divide first to avoid overflow
  3. Multiply by b

private static void reverseHelper(int[] arr, int l, int r) {

Problem 43: Highest and Lowest Frequency Elementmedium

Question Statement

Return {highestFreqElement, lowestFreqElement}; ties pick smaller.

Input: arr=[10,5,10,15,10,5]
Output:
[10,15]

Brute force

Count each element by scanning, O(n^2).

Optimized idea

Build a frequency map and scan it for max and min with tie-breaking.

Why it works

One pass for counts and one over distinct keys is O(n).

Java implementation

public static int[] highLowFrequency(int[] arr) {
    Map<Integer, Integer> m = new HashMap<>();
    for (int x : arr) m.merge(x, 1, Integer::sum);
    int hi = -1, lo = -1, hf = 0, lf = Integer.MAX_VALUE;
    for (Map.Entry<Integer, Integer> e : m.entrySet()) {
        int k = e.getKey(), f = e.getValue();
        if (f > hf || (f == hf && k < hi)) { hf = f; hi = k; }
        if (f < lf || (f == lf && k < lo)) { lf = f; lo = k; }
    }
    return new int[]{hi, lo};
}

Explanation

  1. Count frequencies
  2. Track the best max (ties pick smaller)
  3. Track the best min (ties pick smaller)
  4. Return both
