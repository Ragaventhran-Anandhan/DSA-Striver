Problem 455: Minimum Characters to Add at Front for Palindromemedium

Question Statement

Min chars at front.

Input: s="aacecaaa"
Output:
1

Brute force

Try adding characters until the string is a palindrome.

Optimized idea

Length minus the longest palindromic prefix, found with the KMP LPS of s + "#" + reverse(s).

Why it works

The LPS value at the end is the length of the longest prefix that is also a suffix of the reverse, i.e. a palindromic prefix.

Java implementation

public static int minCharsForPalindrome(String s) {
    String t = s + "#" + new StringBuilder(s).reverse();
    int[] lps = new int[t.length()];
    for (int i = 1, k = 0; i < t.length(); i++) {
        while (k > 0 && t.charAt(i) != t.charAt(k)) k = lps[k - 1];
        if (t.charAt(i) == t.charAt(k)) k++;
        lps[i] = k;
    }
    return s.length() - lps[t.length() - 1];
}

Explanation

  1. t = s + "#" + reverse(s)
  2. Compute the LPS array
  3. answer = n - lps[last]

Problem 456: Shortest Palindromemedium

Question Statement

Shortest palindrome by adding at front.

Input: s="aacecaaa"
Output:
"aaacecaaa"

Brute force

Try each prefix to see if it is a palindrome.

Optimized idea

Find the longest palindromic prefix with LPS and prepend the reversed remainder.

Why it works

Only the part after the palindromic prefix needs to be mirrored.

Java implementation

public static String shortestPalindrome(String s) {
    String t = s + "#" + new StringBuilder(s).reverse();
    int[] lps = new int[t.length()];
    for (int i = 1, k = 0; i < t.length(); i++) {
        while (k > 0 && t.charAt(i) != t.charAt(k)) k = lps[k - 1];
        if (t.charAt(i) == t.charAt(k)) k++;
        lps[i] = k;
    }
    int p = lps[t.length() - 1];
    return new StringBuilder(s.substring(p)).reverse() + s;
}

Explanation

  1. Compute the longest palindromic prefix length p
  2. Reverse s[p..]
  3. Prepend it to s

Problem 457: Rabin-Karp Algorithmmedium

Question Statement

Pattern match using rolling hash.

Input: text="abcabc", pattern="bc"
Output:
[1,4]

Brute force

Compare the pattern at every position, O(nm).

Optimized idea

Rolling hash: update the window hash in O(1) and verify on a hash match.

Why it works

Equal hashes are candidates; verifying avoids false positives, giving O(n + m) on average.

Java implementation

public static List<Integer> rabinKarp(String text, String pattern) {
    List<Integer> res = new ArrayList<>();
    int n = text.length(), m = pattern.length();
    if (m > n) return res;
    long B = 256, M = 1_000_000_007L, h = 1, ph = 0, th = 0;
    for (int i = 0; i < m - 1; i++) h = h * B % M;
    for (int i = 0; i < m; i++) {
        ph = (ph * B + pattern.charAt(i)) % M;
        th = (th * B + text.charAt(i)) % M;
    }
    for (int i = 0; i + m <= n; i++) {
        if (ph == th && text.startsWith(pattern, i)) res.add(i);
        if (i + m < n) th = ((th - text.charAt(i) * h % M + M) * B + text.charAt(i + m)) % M;
    }
    return res;
}

Explanation

  1. Hash the pattern and the first window
  2. Roll: remove the left char and add the right
  3. On equal hash compare the strings
  4. Record the index

Problem 458: Z-Functionmedium

Question Statement

Compute Z array.

Input: s="aabxaab"
Output:
[7,1,0,0,3,1,0]

Brute force

Compare each suffix with the string character by character, O(n^2).

Optimized idea

Z-algorithm maintaining a window [l, r] that matches a prefix.

Why it works

Values inside the window are reused from earlier results, so the total work is O(n).

Java implementation

public static int[] zFunction(String s) {
    int n = s.length();
    int[] z = new int[n];
    z[0] = n;
    for (int i = 1, l = 0, r = 0; i < n; i++) {
        if (i <= r) z[i] = Math.min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) z[i]++;
        if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; }
    }
    return z;
}

Explanation

  1. z[0] = n
  2. If i <= r start from min(r - i + 1, z[i - l])
  3. Extend while characters match
  4. Update the window

Problem 459: KMP Algorithm / LPS Arraymedium

Question Statement

Longest prefix suffix array.

Input: pattern="abab"
Output:
[0,0,1,2]

Brute force

For every prefix check all border lengths.

Optimized idea

Build the LPS array incrementally, falling back with lps[k-1] on a mismatch.

Why it works

A border of a prefix extends from a shorter border, so mismatches reuse earlier values.

Java implementation

public static int[] computeLPS(String pattern) {
    int n = pattern.length();
    int[] lps = new int[n];
    for (int i = 1, k = 0; i < n; i++) {
        while (k > 0 && pattern.charAt(i) != pattern.charAt(k)) k = lps[k - 1];
        if (pattern.charAt(i) == pattern.charAt(k)) k++;
        lps[i] = k;
    }
    return lps;
}

Explanation

  1. lps[0] = 0, k = 0
  2. If chars match k++ and store
  3. Else fall back k = lps[k-1]
  4. Store lps[i] = k

Problem 460: KMP - Find Pattern Occurrencesmedium

Question Statement

All start indices.

Input: text="aabaabaa", pattern="aab"
Output:
[0,3]

Brute force

Compare the pattern at each text position.

Optimized idea

KMP: never move backwards in the text, use LPS to shift the pattern.

Why it works

After a mismatch the LPS tells how much of the pattern still matches, giving O(n + m).

Java implementation

public static List<Integer> kmpSearch(String text, String pattern) {
    List<Integer> res = new ArrayList<>();
    int m = pattern.length();
    int[] lps = new int[m];
    for (int i = 1, k = 0; i < m; i++) {
        while (k > 0 && pattern.charAt(i) != pattern.charAt(k)) k = lps[k - 1];
        if (pattern.charAt(i) == pattern.charAt(k)) k++;
        lps[i] = k;
    }
    for (int i = 0, k = 0; i < text.length(); i++) {
        while (k > 0 && text.charAt(i) != pattern.charAt(k)) k = lps[k - 1];
        if (text.charAt(i) == pattern.charAt(k)) k++;
        if (k == m) { res.add(i - m + 1); k = lps[k - 1]; }
    }
    return res;
}

Explanation

  1. Compute LPS
  2. Scan text with pattern index k
  3. On a full match record i - m + 1 and set k = lps[k-1]

Problem 461: Count and Saymedium

Question Statement

n-th term.

Input: n=4
Output:
"1211"

Brute force

Recursion generating each term.

Optimized idea

Iteratively build each term by run-length encoding the previous one.

Why it works

Each term is derived only from the one before it.

Java implementation

public static String countAndSay(int n) {
    String s = "1";
    for (int i = 2; i <= n; i++) {
        StringBuilder sb = new StringBuilder();
        for (int j = 0; j < s.length(); ) {
            int k = j;
            while (k < s.length() && s.charAt(k) == s.charAt(j)) k++;
            sb.append(k - j).append(s.charAt(j));
            j = k;
        }
        s = sb.toString();
    }
    return s;
}

Explanation

  1. Start with "1"
  2. For each next term count runs of equal digits
  3. Append count then digit

Problem 462: Compare Version Numbersmedium

Question Statement

Compare.

Input: v1="1.01", v2="1.001"
Output:
0

Brute force

Split and parse every revision into a list.

Optimized idea

Walk both strings parsing revision numbers on the fly.

Why it works

Missing revisions count as 0 and leading zeros vanish when parsed as integers.

Java implementation

public static int compareVersion(String v1, String v2) {
    String[] a = v1.split("\\."), b = v2.split("\\.");
    for (int i = 0; i < Math.max(a.length, b.length); i++) {
        int x = i < a.length ? Integer.parseInt(a[i]) : 0;
        int y = i < b.length ? Integer.parseInt(b[i]) : 0;
        if (x != y) return x < y ? -1 : 1;
    }
    return 0;
}

Explanation

  1. Split on '.'
  2. Compare revision by revision
  3. Treat missing as 0
  4. Return -1, 0 or 1

Problem 463: Repeated Substring Patternmedium

Question Statement

Is built by repeating substring.

Input: s="abab"
Output:
true

Brute force

Try every substring length that divides n.

Optimized idea

Check whether s occurs inside (s + s) with the first and last characters removed.

Why it works

A string made of repeats appears in a non-trivial rotation of itself.

Java implementation

public static boolean repeatedSubstringPattern(String s) {
    String d = s + s;
    return d.substring(1, d.length() - 1).contains(s);
}

Explanation

  1. d = s + s
  2. Remove the first and last character
  3. If s is found it is a repeated pattern
