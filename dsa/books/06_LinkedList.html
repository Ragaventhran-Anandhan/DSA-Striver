Problem 143: Introduction: Construct LL from Arrayeasy

Question Statement

Build linked list.

Input: arr=[1,2,3]
Output:
1->2->3

Brute force

Create nodes and wire pointers one by one by hand.

Optimized idea

Keep a tail pointer and append each value.

Why it works

Appending at the tail is O(1) so the whole build is O(n).

Java implementation

public static Node constructLL(int[] arr) {
    Node dummy = new Node(0), t = dummy;
    for (int x : arr) { t.next = new Node(x); t = t.next; }
    return dummy.next;
}

Explanation

  1. Dummy head
  2. For each value create a node and attach at tail
  3. Return dummy.next

Problem 144: Length of Linked Listeasy

Question Statement

Count nodes.

Input: head=1->2->3
Output:
3

Brute force

Copy to an array and take its length.

Optimized idea

Walk the list counting nodes.

Why it works

Every node is visited exactly once.

Java implementation

public static int length(Node head) {
    int c = 0;
    for (Node t = head; t != null; t = t.next) c++;
    return c;
}

Explanation

  1. count = 0
  2. Move head until null
  3. Increment each step

Problem 145: Search in Linked Listeasy

Question Statement

Check if x exists.

Input: head=1->2->3, x=2
Output:
true

Brute force

Same linear scan; there is no faster way on a singly linked list.

Optimized idea

Traverse comparing each value.

Why it works

No random access, so O(n) is the best possible.

Java implementation

public static boolean searchLL(Node head, int x) {
    for (Node t = head; t != null; t = t.next) if (t.val == x) return true;
    return false;
}

Explanation

  1. Walk nodes
  2. Return true on match
  3. Return false at the end

Problem 147: Delete Tail of Linked Listeasy

Question Statement

Remove last node.

Input: head=1->2->3
Output:
1->2

Brute force

Copy all but the last node into a new list.

Optimized idea

Stop at the second-last node and cut the link.

Why it works

Only the pointer of the second-last node changes.

Java implementation

public static Node deleteTail(Node head) {
    if (head == null || head.next == null) return null;
    Node t = head;
    while (t.next.next != null) t = t.next;
    t.next = null;
    return head;
}

Explanation

  2. Walk until t.next.next is null
  3. Set t.next = null

Problem 148: Delete K-th Nodeeasy

Question Statement

Remove node at 1-indexed position k.

Input: head=1->2->3, k=2
Output:
1->3

Brute force

Rebuild the list skipping index k.

Optimized idea

Walk to the (k-1)-th node and bypass the next one.

Why it works

Unlinking needs only the previous node.

Java implementation

public static Node deleteKth(Node head, int k) {
    if (head == null) return null;
    if (k == 1) return head.next;
    Node t = head;
    for (int i = 1; i < k - 1 && t.next != null; i++) t = t.next;
    if (t.next != null) t.next = t.next.next;
    return head;
}

Explanation

  1. If k == 1 return head.next
  2. Move to position k-1
  3. prev.next = prev.next.next

Problem 153: Construct DLL from Arrayeasy

Question Statement

Build doubly linked list.

Input: arr=[1,2,3]
Output:
1<->2<->3

Brute force

Create nodes and link by hand.

Optimized idea

Keep a tail and set both next and prev.

Why it works

Doubly linked requires updating two pointers per insertion.

Java implementation

public static DNode constructDLL(int[] arr) {
    if (arr.length == 0) return null;
    DNode head = new DNode(arr[0]), t = head;
    for (int i = 1; i < arr.length; i++) {
        DNode n = new DNode(arr[i]);
        t.next = n; n.prev = t; t = n;
    }
    return head;
}

Explanation

  1. Start with the first node
  2. For each value link tail.next and node.prev
  3. Advance tail

Problem 158: Reverse a DLLeasy

Question Statement

Reverse the list.

Input: head=1<->2<->3
Output:
3<->2<->1

Brute force

Copy values to an array and rewrite reversed.

Optimized idea

Swap prev and next in every node.

Why it works

Reversing direction of links reverses the list in place.

Java implementation

public static DNode reverseDLL(DNode head) {
    DNode cur = head, last = null;
    while (cur != null) {
        last = cur.prev;
        cur.prev = cur.next;
        cur.next = last;
        cur = cur.prev;
    }
    return last == null ? head : last.prev;
}

Explanation

  1. Walk through the list
  2. Swap prev and next for each node
  3. New head is the last visited node

Optimized idea

Reverse pointers while walking.

Why it works

Each node's next is redirected to its previous node.

public static Node reverseIterative(Node head) {
    Node prev = null;

        Node nx = head.next;

        head = nx;

    return prev;
}

  4. Advance

Problem 162: Detect a Loopeasy

Question Statement

True if there is a cycle.

Input: head=3->2->0->-4->(back to 2)
Output:
true

Brute force

Store visited nodes in a HashSet.

Optimized idea

Floyd tortoise and hare.

Why it works

In a cycle the fast pointer eventually laps the slow one.

Java implementation

public static boolean hasCycle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

Explanation

  1. slow, fast
  2. Move 1 and 2 steps
  3. If they meet there is a cycle

Problem 163: Check if Linked List is Palindromeeasy

Question Statement

Check palindrome.

Input: head=1->2->2->1
Output:
true

Brute force

Copy values to an array and check it.

Optimized idea

Find the middle, reverse the second half, compare.

Why it works

O(1) extra space comparing halves.

Java implementation

public static boolean isPalindromeLL(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
    Node prev = null;
    while (slow != null) { Node nx = slow.next; slow.next = prev; prev = slow; slow = nx; }
    for (Node a = head, b = prev; b != null; a = a.next, b = b.next) if (a.val != b.val) return false;
    return true;
}

Explanation

  1. Find the middle
  2. Reverse the second half
  3. Compare both halves
  4. Return the result

Problem 164: Sort a List of 0s, 1s and 2seasy

Question Statement

Sort list of 0/1/2.

Input: head=1->0->2->1
Output:
0->1->1->2

Brute force

Sort the values with any sort.

Optimized idea

Three dummy lists for 0, 1, 2 then join.

Why it works

One pass and no value changes, only relinking.

Java implementation

public static Node sortZeroOneTwo(Node head) {
    Node z = new Node(0), o = new Node(0), t = new Node(0);
    Node zt = z, ot = o, tt = t;
    for (Node c = head; c != null; c = c.next) {
        if (c.val == 0) { zt.next = c; zt = c; }
        else if (c.val == 1) { ot.next = c; ot = c; }
        else { tt.next = c; tt = c; }
    }
    zt.next = o.next != null ? o.next : t.next;
    ot.next = t.next;
    tt.next = null;
    return z.next;
}

Explanation

  1. Three heads and tails
  2. Append each node to its list
  3. Join zero->one->two

Problem 165: Add 1 to a Number Represented by LLeasy

Question Statement

Digits in list, add one.

Input: head=1->2->9
Output:
1->3->0

Brute force

Convert to a number and add one (overflows).

Optimized idea

Recursive carry from the tail.

Why it works

Carry propagates from the last digit backwards.

Java implementation

public static Node addOne(Node head) {
    int carry = helper(head);
    if (carry == 1) { Node n = new Node(1); n.next = head; return n; }
    return head;
}

private static int helper(Node n) {
    if (n == null) return 1;
    int sum = n.val + helper(n.next);
    n.val = sum % 10;
    return sum / 10;
}

Explanation

  1. Recurse to the end
  2. Add 1 and compute carry on the way back
  3. If carry remains prepend a node

Problem 166: Delete All Occurrences of Key in DLLmedium

Question Statement

Remove every node with key.

Input: head=1<->2<->1<->3, key=1
Output:
2<->3

Brute force

Rebuild without the key.

Optimized idea

Walk once and unlink every node holding key.

Why it works

Doubly links let each deletion be O(1).

Java implementation

public static DNode deleteAllOccurrences(DNode head, int key) {
    DNode t = head;
    while (t != null) {
        DNode nx = t.next;
        if (t.val == key) {
            if (t.prev != null) t.prev.next = t.next; else head = t.next;
            if (t.next != null) t.next.prev = t.prev;
        }
        t = nx;
    }
    return head;
}

Explanation

  1. Walk nodes
  2. If val == key unlink
  3. If it was the head move head

Problem 167: Find Pairs with Given Sum in Sorted DLLmedium

Question Statement

All pairs summing to target.

Input: head=1<->2<->4<->5<->6<->8<->9, target=7
Output:
[[1,6],[2,5]]

Brute force

Try every pair, O(n^2).

Optimized idea

Two pointers from head and tail of the sorted list.

Why it works

Sorted order lets the pointers move by comparing the sum.

Java implementation

public static List<int[]> findPairsDLL(DNode head, int target) {
    List<int[]> res = new ArrayList<>();
    if (head == null) return res;
    DNode l = head, r = head;
    while (r.next != null) r = r.next;
    while (l != r && r.next != l) {
        int s = l.val + r.val;
        if (s == target) { res.add(new int[]{l.val, r.val}); l = l.next; r = r.prev; }
        else if (s < target) l = l.next;
        else r = r.prev;
    }
    return res;
}

Explanation

  1. Find tail
  2. While l != r and r.next != l compute sum
  3. Record pairs and move both
  4. Else move one pointer

Problem 168: Remove Duplicates from Sorted DLLmedium

Remove duplicate nodes.

Input: head=1<->1<->2<->3<->3
Output:
1<->2<->3

Brute force

Use a set and rebuild.

Optimized idea

Skip nodes equal to the next one.

Why it works

Sorted means duplicates are adjacent.

Java implementation

public static DNode removeDuplicatesDLL(DNode head) {
    DNode t = head;
    while (t != null && t.next != null) {
        if (t.val == t.next.val) {
            DNode d = t.next;

}

  3. Move forward

Problem 169: Find Starting Point of Loopmedium

Question Statement

Return node where cycle begins.

Input: head=3->2->0->-4->(back to 2)
Output:
node 2

Brute force

Store visited nodes in a set; the first repeat is the start.

Optimized idea

Floyd, then restart one pointer at head.

Why it works

Distance from head to cycle start equals distance from meeting point to cycle start.

Java implementation

public static Node detectCycle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            slow = head;
            while (slow != fast) { slow = slow.next; fast = fast.next; }
            return slow;
        }
    }
    return null;
}

Explanation

  1. Find the meeting point
  2. slow = head
  3. Move both one step until they meet
  4. That node is the start

Problem 170: Length of Loopmedium

Length of the cycle, 0 if none.

Input: head=3->2->0->-4->(back to 2)
Output:
3

Brute force

Store indexes in a map to compute the gap.

Optimized idea

After the meeting point count steps to return.

One lap around the cycle equals its length.

        slow = slow.next;

Problem 174: Sort Linked Listmedium

Question Statement

Sort using merge sort.

Input: head=4->2->1->3
Output:
1->2->3->4

Brute force

Copy values to an array, sort, rebuild.

Optimized idea

Merge sort on the list using middle split and merge.

Why it works

Merge sort needs no random access and is O(n log n).

Java implementation

public static Node sortList(Node head) {
    if (head == null || head.next == null) return head;
    Node slow = head, fast = head.next;
    while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
    Node right = slow.next;
    slow.next = null;
    Node a = sortList(head), b = sortList(right);
    Node d = new Node(0), t = d;
    while (a != null && b != null) {
        if (a.val <= b.val) { t.next = a; a = a.next; } else { t.next = b; b = b.next; }
        t = t.next;
    }
    t.next = a != null ? a : b;
    return d.next;
}

Explanation

  1. Find the middle
  2. Sort each half

Problem 175: Intersection of Two Linked Listsmedium

Question Statement

Return intersecting node.

Input: a=4->1->8->4->5, b=5->6->1->8->4->5
Output:
node 8

Brute force

Store all nodes of one list in a set.

Optimized idea

Two pointers that switch lists at the end.

Why it works

Both pointers travel lenA + lenB nodes, so they meet at the intersection.

Java implementation

public static Node getIntersectionNode(Node a, Node b) {
    Node p = a, q = b;
    while (p != q) {
        p = p == null ? b : p.next;
        q = q == null ? a : q.next;
    }
    return p;
}

Explanation

  1. p = a, q = b
  2. Move both; at null jump to the other head
  3. Stop when p == q

Problem 176: Add Two Numbersmedium

Question Statement

Digits stored in reverse order.

Input: a=2->4->3, b=5->6->4
Output:
7->0->8

Brute force

Convert to numbers and add (overflow risk).

Optimized idea

Digit-by-digit addition with carry.

Why it works

Digits are in reverse order so the least significant digit comes first.

Java implementation

public static Node addTwoNumbers(Node a, Node b) {
    Node d = new Node(0), t = d;
    int carry = 0;
    while (a != null || b != null || carry != 0) {
        int s = carry + (a != null ? a.val : 0) + (b != null ? b.val : 0);
        t.next = new Node(s % 10);
        t = t.next;
        carry = s / 10;
        if (a != null) a = a.next;
        if (b != null) b = b.next;
    }
    return d.next;
}

Explanation

  1. Dummy head and carry
  2. Sum digits plus carry
  3. Create a node for sum%10
  4. Continue until lists and carry end

Problem 177: Rotate Listmedium

Question Statement

Rotate right by k places.

Input: head=1->2->3->4->5, k=2
Output:
4->5->1->2->3

Brute force

Rotate by one, k times.

Optimized idea

Make the list circular and cut at length-k.

Why it works

The new tail is at position len-k%len.

Java implementation

public static Node rotateRight(Node head, int k) {
    if (head == null || head.next == null || k == 0) return head;
    int len = 1;
    Node tail = head;
    while (tail.next != null) { tail = tail.next; len++; }
    k %= len;
    if (k == 0) return head;
    tail.next = head;
    Node t = head;
    for (int i = 1; i < len - k; i++) t = t.next;
    Node nh = t.next;
    t.next = null;
    return nh;
}

Explanation

  1. Find length and tail
  2. tail.next = head
  3. Move len-k%len steps
  4. Cut the cycle

Problem 178: Reverse Nodes in K-Grouphard

Question Statement

Reverse every k nodes.

Input: head=1->2->3->4->5, k=2
Output:
2->1->4->3->5

Brute force

Copy values to an array and reverse segments.

Optimized idea

Reverse each k nodes in place, linking groups.

Why it works

A group is reversed only if k nodes exist.

Java implementation

public static Node reverseKGroup(Node head, int k) {
    Node t = head;
    for (int i = 0; i < k; i++) {
        if (t == null) return head;
        t = t.next;
    }
    Node prev = null, cur = head;
    for (int i = 0; i < k; i++) { Node nx = cur.next; cur.next = prev; prev = cur; cur = nx; }
    head.next = reverseKGroup(cur, k);
    return prev;
}

Explanation

  1. Check k nodes remain
  2. Reverse the group
  3. Connect with the result of the rest

Problem 179: Flatten a Linked Listhard

Question Statement

Each node has next and bottom (sorted); flatten via bottom.

Input: 5->10->19->28 with bottoms
Output:
sorted bottom chain

Brute force

Collect every value, sort, rebuild with bottom pointers.

Optimized idea

Merge bottom lists pairwise recursively.

Why it works

Each column is sorted, so merging two sorted lists repeatedly keeps order.

Java implementation

public static Node flatten(Node head) {
    if (head == null || head.next == null) return head;
    head.next = flatten(head.next);
    return mergeBottom(head, head.next);
}

private static Node mergeBottom(Node a, Node b) {
    Node d = new Node(0), t = d;
    while (a != null && b != null) {
        if (a.val <= b.val) { t.bottom = a; a = a.bottom; } else { t.bottom = b; b = b.bottom; }
        t = t.bottom;
    }
    t.bottom = a != null ? a : b;
    d.bottom.next = null;
    return d.bottom;
}

Explanation

  1. Flatten the rest first
  2. Merge head with the flattened rest through bottom
  3. Return merged head

Problem 180: Copy List with Random Pointerhard

Question Statement

Deep copy list with random pointers.

Input: head=[[7,null],[13,0],[11,4]]
Output:
deep copy

Brute force

HashMap from old to new nodes (O(n) extra space).

Optimized idea

Interleave copies, set randoms, split.

Why it works

Copy sits right after the original, so copy.random = original.random.next.

Java implementation

public static Node copyRandomList(Node head) {
    if (head == null) return null;
    for (Node t = head; t != null; t = t.next.next) {
        Node c = new Node(t.val);
        c.next = t.next;
        t.next = c;
    }
    for (Node t = head; t != null; t = t.next.next)
        if (t.random != null) t.next.random = t.random.next;
    Node nh = head.next;
    for (Node t = head; t != null; t = t.next) {
        Node c = t.next;
        t.next = c.next;
        if (c.next != null) c.next = c.next.next;
    }
    return nh;
}

Explanation

  1. Insert a copy after each node
  2. Set copy random pointers
  3. Separate the two lists
