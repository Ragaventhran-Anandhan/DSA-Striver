Problem 51: Largest Element in Arrayeasy

Question Statement

Return the largest element.

Input: arr=[3,2,1,5,2]
Output:
5

Brute force

Sort and take the last element.

Optimized idea

One scan keeping the maximum.

Why it works

Every element is compared once so O(n).

Java implementation

public static int findLargest(int[] arr) {
    int max = arr[0];
    for (int x : arr) if (x > max) max = x;
    return max;
}

Explanation

  1. max = arr[0]
  2. Update max when a larger value appears
  3. Return max

Problem 52: Second Largest Elementeasy

Question Statement

Return second largest distinct element, -1 if none.

Input: arr=[1,2,4,7,7,5]
Output:
5

Brute force

Sort and pick the second distinct from the end.

Optimized idea

Single pass tracking largest and second largest.

Why it works

Strictly smaller than the largest and bigger than the current second keeps them distinct.

Java implementation

public static int secondLargest(int[] arr) {
    int large = Integer.MIN_VALUE, second = -1;
    for (int x : arr) {
        if (x > large) { second = large == Integer.MIN_VALUE ? -1 : large; large = x; }
        else if (x < large && x > second) second = x;
    }
    return second;
}

Explanation

  1. largest = MIN, second = -1
  2. If x > largest then second = largest, largest = x
  3. Else if x < largest and x > second then second = x

Problem 53: Check if Array is Sortedeasy

Question Statement

True if non-decreasing order.

Input: arr=[1,2,3,4,5]
Output:
true

Brute force

Sort a copy and compare.

Optimized idea

Check every adjacent pair.

Why it works

Non-decreasing order is exactly a[i] <= a[i+1] for all i.

Java implementation

public static boolean isSorted(int[] arr) {
    for (int i = 1; i < arr.length; i++) if (arr[i] < arr[i - 1]) return false;
    return true;
}

Explanation

  1. Loop i from 1
  2. Return false if arr[i] < arr[i-1]
  3. Return true

Problem 54: Remove Duplicates from Sorted Arrayeasy

Question Statement

In place; return count of unique elements.

Input: arr=[1,1,2,2,2,3,3]
Output:
3, arr=[1,2,3,_,_,_,_]

Brute force

Put elements in a LinkedHashSet and copy back.

Optimized idea

Two pointers: i marks the last unique, j scans.

Why it works

Sorted order means duplicates are adjacent.

Java implementation

public static int removeDuplicates(int[] arr) {
    if (arr.length == 0) return 0;
    int i = 0;
    for (int j = 1; j < arr.length; j++)
        if (arr[j] != arr[i]) arr[++i] = arr[j];
    return i + 1;
}

Explanation

  1. i = 0
  2. For each j, if arr[j] != arr[i] then arr[++i] = arr[j]
  3. Return i+1

Problem 55: Left Rotate Array by Oneeasy

Question Statement

Rotate left by 1 place.

Input: arr=[1,2,3,4,5]
Output:
[2,3,4,5,1]

Brute force

Copy into a temp array shifted by one.

Optimized idea

Save the first element, shift the rest left, put it at the end.

Why it works

Only one element needs extra storage.

Java implementation

public static void rotateByOne(int[] arr) {
    if (arr.length == 0) return;
    int t = arr[0];
    for (int i = 1; i < arr.length; i++) arr[i - 1] = arr[i];
    arr[arr.length - 1] = t;
}

Explanation

  1. temp = arr[0]
  2. Shift arr[1..] left
  3. arr[n-1] = temp

Problem 56: Left Rotate Array by D Placeseasy

Question Statement

Rotate left by d places.

Input: arr=[1,2,3,4,5,6,7], d=3
Output:
[4,5,6,7,1,2,3]

Brute force

Rotate by one, d times, O(n*d).

Optimized idea

Reversal algorithm: reverse first d, reverse the rest, reverse all.

Why it works

Three reversals compose to a left rotation in O(n) and O(1) space.

Java implementation

public static void rotateByD(int[] arr, int d) {
    int n = arr.length;
    if (n == 0) return;
    d %= n;
    reverse(arr, 0, d - 1);
    reverse(arr, d, n - 1);
    reverse(arr, 0, n - 1);
}

private static void reverse(int[] a, int l, int r) {
    while (l < r) { int t = a[l]; a[l++] = a[r]; a[r--] = t; }
}

Explanation

  1. d %= n
  2. Reverse [0, d-1]
  3. Reverse [d, n-1]
  4. Reverse the whole array

Problem 57: Move Zeros to Endeasy

Question Statement

Move all zeros to end, keep order of others.

Input: arr=[1,0,2,3,0,4,0,1]
Output:
[1,2,3,4,1,0,0,0]

Brute force

Copy non-zeros to a temp list then pad with zeros.

Optimized idea

Two pointers: write non-zero values forward, fill the rest with zeros.

Why it works

Non-zero order is preserved because we move forward only.

Java implementation

public static void moveZeros(int[] arr) {
    int pos = 0;
    for (int x : arr) if (x != 0) arr[pos++] = x;
    while (pos < arr.length) arr[pos++] = 0;
}

Explanation

  1. pos = 0
  2. Copy each non-zero to arr[pos++]
  3. Fill the remainder with 0

Problem 59: Union of Two Sorted Arrayseasy

Question Statement

Sorted union without duplicates.

Input: a=[1,2,3,4,5], b=[2,3,4,4,5]
Output:
[1,2,3,4,5]

Brute force

Put both arrays in a TreeSet.

Optimized idea

Merge with two pointers, skipping duplicates.

Why it works

Both arrays are sorted, so the merged output is sorted with O(n+m).

Java implementation

public static List<Integer> unionSorted(int[] a, int[] b) {
    List<Integer> r = new ArrayList<>();
    int i = 0, j = 0;
    while (i < a.length || j < b.length) {
        int v;
        if (j >= b.length || (i < a.length && a[i] <= b[j])) v = a[i++];
        else v = b[j++];
        if (r.isEmpty() || r.get(r.size() - 1) != v) r.add(v);
    }
    return r;
}

Explanation

  1. Compare a[i] and b[j]
  2. Add the smaller if it differs from the last added
  3. Advance that pointer
  4. Drain the leftovers

Problem 60: Intersection of Two Sorted Arrayseasy

Question Statement

Common elements (with multiplicity).

Input: a=[1,2,2,3,3,4,5,6], b=[2,3,3,5,6,6,7]
Output:
[2,3,3,5,6]

Brute force

For each element of a search in b.

Optimized idea

Two pointers over the sorted arrays.

Why it works

Equal elements are matched once; the smaller side advances otherwise.

Java implementation

public static List<Integer> intersection(int[] a, int[] b) {
    List<Integer> r = new ArrayList<>();
    int i = 0, j = 0;
    while (i < a.length && j < b.length) {
        if (a[i] == b[j]) { r.add(a[i]); i++; j++; }
        else if (a[i] < b[j]) i++;
        else j++;
    }
    return r;
}

Explanation

  1. i = j = 0
  2. If equal add and advance both
  3. Else advance the pointer with smaller value

Problem 61: Find Missing Numbereasy

Question Statement

Array has n-1 distinct numbers from 1..n; find missing.

Input: arr=[1,2,4,5], n=5
Output:
3

Brute force

For each number 1..n check if it exists, O(n^2).

Optimized idea

Expected sum n(n+1)/2 minus actual sum (or XOR).

Why it works

The only number absent from the sum is the missing one.

Java implementation

public static int missingNumber(int[] arr, int n) {
    long expected = (long) n * (n + 1) / 2, sum = 0;
    for (int x : arr) sum += x;
    return (int) (expected - sum);
}

Explanation

  1. expected = n*(n+1)/2
  2. actual = sum of array
  3. Return the difference

Optimized idea

  3. best = max(best, cur)

Problem 64: Two Sumeasy

Question Statement

Return indices of two numbers adding to target.

Input: arr=[2,6,5,8,11], target=14
Output:
[1,3]

Brute force

Try all pairs, O(n^2).

Optimized idea

HashMap of value to index; look up target - x.

Why it works

Each element needs one O(1) lookup for its complement.

Java implementation

public static int[] twoSum(int[] arr, int target) {
    Map<Integer, Integer> m = new HashMap<>();
    for (int i = 0; i < arr.length; i++) {
        Integer j = m.get(target - arr[i]);
        if (j != null) return new int[]{j, i};
        m.put(arr[i], i);
    }
    return new int[]{-1, -1};
}

Explanation

  1. For each i compute need = target - arr[i]
  2. If need is in the map return both indices
  3. Otherwise store arr[i] -> i

Problem 65: Merge Two Sorted Arrays Without Extra Spaceeasy

Question Statement

Merge so a holds smallest, b the rest.

Input: a=[1,4,8,10], b=[2,3,9]
Output:
a=[1,2,3,4], b=[8,9,10]

Brute force

Merge into a temp array then split.

Optimized idea

Swap from the ends then sort both (or gap method).

Why it works

Comparing a's largest with b's smallest moves each misplaced element across until arrays are partitioned.

Java implementation

public static void mergeSortedInPlace(int[] a, int[] b) {
    int i = a.length - 1, j = 0;
    while (i >= 0 && j < b.length && a[i] > b[j]) {
        int t = a[i]; a[i] = b[j]; b[j] = t;
        i--; j++;
    }
    Arrays.sort(a);
    Arrays.sort(b);
}

Explanation

  1. i = n-1, j = 0
  2. While a[i] > b[j] swap and move inward
  3. Sort both arrays

Problem 66: Pascal's Triangle - Element at (r,c)easy

Question Statement

Value at row r column c (1-indexed).

Input: r=5, c=3
Output:
6

Brute force

Build the whole triangle up to row r.

Optimized idea

nCr formula with r-1 choose c-1 computed iteratively.

Why it works

Multiplying and dividing step by step avoids factorials and overflow for small inputs.

Java implementation

public static int pascalElement(int r, int c) {
    int n = r - 1, k = c - 1;
    long res = 1;
    for (int i = 0; i < k; i++) res = res * (n - i) / (i + 1);
    return (int) res;
}

Explanation

  1. n = r-1, k = c-1
  2. res = 1
  3. For i in 0..k-1 res = res*(n-i)/(i+1)

Problem 67: Longest Subarray with Sum K (Positives)medium

Question Statement

Length of longest subarray with sum k.

Input: arr=[2,3,5], k=5
Output:
2

Brute force

Check all subarrays, O(n^2).

Optimized idea

Sliding window since all values are positive.

Why it works

Shrinking from the left lowers the sum, expanding raises it, so each element enters and leaves once.

Java implementation

public static int longestSubarrayPositive(int[] arr, int k) {
    int l = 0, best = 0;
    long sum = 0;
    for (int r = 0; r < arr.length; r++) {
        sum += arr[r];
        while (sum > k && l <= r) sum -= arr[l++];
        if (sum == k) best = Math.max(best, r - l + 1);
    }
    return best;
}

Explanation

  1. Expand right and add
  2. While sum > k shrink left
  3. If sum == k update max length

Problem 68: Longest Subarray with Sum K (Positives and Negatives)medium

Question Statement

Length of longest subarray with sum k.

Input: arr=[10,5,2,7,1,9], k=15
Output:
4

Brute force

Check all subarrays, O(n^2).

Optimized idea

Prefix sum with a HashMap of first occurrence.

Why it works

Subarray (i, j] sums to k when prefix[j] - prefix[i] = k; the earliest i gives the longest length.

Java implementation

public static int longestSubarrayWithSumK(int[] arr, int k) {
    Map<Long, Integer> first = new HashMap<>();
    long sum = 0;
    int best = 0;
    for (int i = 0; i < arr.length; i++) {
        sum += arr[i];
        if (sum == k) best = i + 1;
        Integer j = first.get(sum - k);
        if (j != null) best = Math.max(best, i - j);
        first.putIfAbsent(sum, i);
    }
    return best;
}

Explanation

  1. Keep running sum
  2. If sum == k update length
  3. Look up sum-k in the map
  4. Store sum only if absent

Problem 69: Sort Colors (0s, 1s, 2s)medium

Question Statement

Sort array of 0,1,2 in one pass.

Input: arr=[2,0,2,1,1,0]
Output:
[0,0,1,1,2,2]

Brute force

Sort the array.

Optimized idea

Dutch National Flag with low, mid, high.

Why it works

Zeros go to the front, twos to the back, ones remain in the middle in one pass.

Java implementation

public static void sortColors(int[] arr) {
    int lo = 0, mid = 0, hi = arr.length - 1;
    while (mid <= hi) {
        if (arr[mid] == 0) { int t = arr[lo]; arr[lo++] = arr[mid]; arr[mid++] = t; }
        else if (arr[mid] == 1) mid++;
        else { int t = arr[hi]; arr[hi--] = arr[mid]; arr[mid] = t; }
    }
}

Explanation

  1. low = mid = 0, high = n-1
  2. 0 swaps with low
  3. 2 swaps with high
  4. 1 moves mid

Problem 70: Majority Element (> n/2)medium

Question Statement

Element appearing more than n/2 times.

Input: arr=[2,2,1,1,1,2,2]
Output:
2

Brute force

Count every element with a nested loop.

Optimized idea

Boyer-Moore voting.

Why it works

The majority element survives cancellation with all other elements.

Java implementation

public static int majorityElement(int[] arr) {
    int cand = 0, count = 0;
    for (int x : arr) {
        if (count == 0) cand = x;
        count += x == cand ? 1 : -1;
    }
    return cand;
}

Explanation

  1. cand = none, count = 0
  2. If count == 0 pick current as candidate
  3. Same increments else decrements
  4. Return the candidate

Problem 71: Maximum Subarray Sum (Kadane)medium

Question Statement

Largest sum of a contiguous subarray.

Input: arr=[-2,1,-3,4,-1,2,1,-5,4]
Output:
6

Brute force

Sum every subarray, O(n^2).

Optimized idea

Kadane: extend the current sum or restart at x.

Why it works

A negative running sum can never help a later subarray.

Java implementation

public static int maxSubarraySum(int[] arr) {
    int cur = arr[0], best = arr[0];
    for (int i = 1; i < arr.length; i++) {
        cur = Math.max(arr[i], cur + arr[i]);
        best = Math.max(best, cur);
    }
    return best;
}

Explanation

  1. cur = best = arr[0]
  2. cur = max(x, cur + x)
  3. best = max(best, cur)

Problem 72: Print Subarray with Maximum Summedium

Question Statement

Return the subarray with maximum sum.

Input: arr=[-2,1,-3,4,-1,2,1,-5,4]
Output:
[4,-1,2,1]

Brute force

Check every subarray and track the best.

Optimized idea

Kadane with start index tracking.

Why it works

When the sum resets, the new subarray begins at the current index.

Java implementation

public static int[] maxSubarray(int[] arr) {
    int cur = 0, best = Integer.MIN_VALUE, start = 0, bs = 0, be = 0;
    for (int i = 0; i < arr.length; i++) {
        if (cur <= 0) { cur = arr[i]; start = i; } else cur += arr[i];
        if (cur > best) { best = cur; bs = start; be = i; }
    }
    return Arrays.copyOfRange(arr, bs, be + 1);
}

Explanation

  1. Track start of the current run
  2. On reset update start
  3. When best improves record start and end
  4. Copy the range

Try every buy and sell pair.

Question Statement

Alternate positive and negative starting with positive.

Input: arr=[1,2,-4,-5]
Output:
[1,-4,2,-5]

Brute force

Separate positives and negatives then merge alternately.

Optimized idea

Same idea with two index pointers writing into a result array.

Why it works

Positives go to even positions and negatives to odd positions as they appear.

public static int[] rearrangeBySign(int[] arr) {
    int[] res = new int[arr.length];
    int pos = 0, neg = 1;

Problem 75: Rearrange Array by Sign (Unequal Counts)medium

Question Statement

Alternate signs, leftovers appended at end.

Input: arr=[1,2,-4,-5,3,4]
Output:
[1,-4,2,-5,3,4]

Brute force

Same as the equal-count case with checks.

Optimized idea

Collect positives and negatives separately, interleave, append leftovers.

Why it works

Order is preserved within each sign group.

Java implementation

public static int[] rearrangeBySignUnequal(int[] arr) {
    List<Integer> pos = new ArrayList<>(), neg = new ArrayList<>();
    for (int x : arr) (x > 0 ? pos : neg).add(x);
    int[] res = new int[arr.length];
    int i = 0, p = 0, n = 0;
    while (p < pos.size() && n < neg.size()) { res[i++] = pos.get(p++); res[i++] = neg.get(n++); }
    while (p < pos.size()) res[i++] = pos.get(p++);
    while (n < neg.size()) res[i++] = neg.get(n++);
    return res;
}

Explanation

  1. Split into pos and neg lists
  2. Interleave while both have items
  3. Append the remaining items

Problem 76: Next Permutationmedium

Question Statement

Rearrange to next lexicographic permutation.

Input: arr=[1,3,2]
Output:
[2,1,3]

Brute force

Generate all permutations and pick the next.

Optimized idea

Find pivot, swap with next larger on the right, reverse suffix.

Why it works

The suffix after the pivot is non-increasing, so reversing gives the smallest suffix.

Java implementation

public static void nextPermutation(int[] arr) {
    int n = arr.length, i = n - 2;
    while (i >= 0 && arr[i] >= arr[i + 1]) i--;
    if (i >= 0) {
        int j = n - 1;
        while (arr[j] <= arr[i]) j--;
        int t = arr[i]; arr[i] = arr[j]; arr[j] = t;
    }
    for (int l = i + 1, r = n - 1; l < r; l++, r--) { int t = arr[l]; arr[l] = arr[r]; arr[r] = t; }
}

Explanation

  1. Find the last i with a[i] < a[i+1]
  2. Find the last j > i with a[j] > a[i]
  3. Swap
  4. Reverse a[i+1..]

Problem 77: Leaders in an Arraymedium

Question Statement

Elements greater than all to their right.

Input: arr=[10,22,12,3,0,6]
Output:
[22,12,6]

Brute force

For each element check everything on its right.

Optimized idea

Scan from the right keeping the maximum so far.

Why it works

An element is a leader iff it is greater than the max to its right.

Java implementation

public static List<Integer> leaders(int[] arr) {
    List<Integer> r = new ArrayList<>();
    int max = Integer.MIN_VALUE;
    for (int i = arr.length - 1; i >= 0; i--) {
        if (arr[i] > max) { r.add(arr[i]); max = arr[i]; }
    }
    Collections.reverse(r);
    return r;
}

Explanation

  1. max = MIN
  2. Walk i from n-1 to 0
  3. If arr[i] > max add and update
  4. Reverse to restore order

Problem 78: Longest Consecutive Sequencemedium

Question Statement

Length of longest run of consecutive integers.

Input: arr=[100,4,200,1,3,2]
Output:
4

Brute force

Sort and count runs, O(n log n).

Optimized idea

Put values in a HashSet and extend only from sequence starts.

Why it works

Starting only where x-1 is absent makes each element visited at most twice.

Java implementation

public static int longestConsecutive(int[] arr) {
    Set<Integer> s = new HashSet<>();
    for (int x : arr) s.add(x);
    int best = 0;
    for (int x : s) {
        if (!s.contains(x - 1)) {
            int y = x;
            while (s.contains(y + 1)) y++;
            best = Math.max(best, y - x + 1);
        }
    }
    return best;
}

Explanation

  1. Insert all into a set
  2. For x with no x-1 start counting upward
  3. Track the longest

Problem 79: Set Matrix Zeroesmedium

Question Statement

If a cell is 0 set its whole row and column to 0.

Input: matrix=[[1,1,1],[1,0,1],[1,1,1]]
Output:
[[1,0,1],[0,0,0],[1,0,1]]

Brute force

Copy the matrix and mark rows/cols for each zero.

Optimized idea

Use first row and column as markers.

Why it works

Markers avoid extra arrays, giving O(1) space.

Java implementation

public static void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean r0 = false, c0 = false;

}

Problem 84: 3Summedium

Question Statement

Unique triplets summing to 0.

Input: arr=[-1,0,1,2,-1,-4]
Output:
[[-1,-1,2],[-1,0,1]]

Brute force

Three loops with a set for uniqueness, O(n^3).

Optimized idea

Sort then fix one element and use two pointers.

Why it works

Sorted order lets pointers move based on the sum and skip duplicates easily.

Java implementation

public static List<List<Integer>> threeSum(int[] arr) {
    Arrays.sort(arr);
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < arr.length - 2; i++) {
        if (i > 0 && arr[i] == arr[i - 1]) continue;
        int l = i + 1, r = arr.length - 1;
        while (l < r) {
            int s = arr[i] + arr[l] + arr[r];
            if (s == 0) {
                res.add(Arrays.asList(arr[i], arr[l], arr[r]));
                l++; r--;
                while (l < r && arr[l] == arr[l - 1]) l++;
                while (l < r && arr[r] == arr[r + 1]) r--;
            } else if (s < 0) l++;
            else r--;
        }
    }
    return res;
}

Explanation

  1. Sort
  2. For each i skip duplicates
  3. Two pointers l and r on the rest
  4. Move based on sum and skip duplicates

[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

Why it works

Reduces to two-sum on the sorted tail, giving O(n^3).

public static List<List<Integer>> fourSum(int[] arr, int target) {

        for (int j = i + 1; j < n - 2; j++) {
            if (j > i + 1 && arr[j] == arr[j - 1]) continue;

                if (s == target) {
                    res.add(Arrays.asList(arr[i], arr[j], arr[l], arr[r]));
                    l++; r--;
                    while (l < r && arr[l] == arr[l - 1]) l++;
                    while (l < r && arr[r] == arr[r + 1]) r--;
                } else if (s < target) l++;
                else r--;
            }
        }
    }
    return res;
}

Explanation

  1. Sort
  2. Fix i and j skipping duplicates

Problem 90: Majority Element II (> n/3)hard

Output:
[1]

Extended Boyer-Moore with two candidates.

At most two elements can exceed n/3 occurrences.

public static List<Integer> majorityElementII(int[] arr) {
    int c1 = 0, c2 = 1, n1 = 0, n2 = 0;
    for (int x : arr) {
        if (x == c1) n1++;
        else if (x == c2) n2++;
        else if (n1 == 0) { c1 = x; n1 = 1; }
        else if (n2 == 0) { c2 = x; n2 = 1; }
        else { n1--; n2--; }

    List<Integer> r = new ArrayList<>();
    if (n1 > arr.length / 3) r.add(c1);
    if (n2 > arr.length / 3) r.add(c2);
    return r;
}

Explanation

  1. Keep two candidates and counts
  2. Update using voting rules
  3. Verify counts of both candidates

Output:
8

Why it works

When a right element goes first, all remaining left elements form inversions with it.

public static long countInversions(int[] arr) {
    return sort(arr.clone(), 0, arr.length - 1);
}

private static long sort(int[] a, int lo, int hi) {
    if (lo >= hi) return 0;
    int mid = (lo + hi) / 2;
    long c = sort(a, lo, mid) + sort(a, mid + 1, hi);
    int[] t = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi) {
        if (a[i] <= a[j]) t[k++] = a[i++];
        else { c += mid - i + 1; t[k++] = a[j++]; }
    }
    while (i <= mid) t[k++] = a[i++];
    while (j <= hi) t[k++] = a[j++];
    System.arraycopy(t, 0, a, lo, t.length);
    return c;
}

  1. Split
  2. Count in each half
  3. During merge if right < left add mid-i+1
