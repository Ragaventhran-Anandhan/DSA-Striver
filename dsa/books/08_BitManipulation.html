Problem 202: Minimum Bit Flips to Convert Numbereasy

Question Statement

Bit flips to convert start to goal.

Input: start=10, goal=7
Output:
3

Brute force

Compare bit by bit with a loop over 32 bits.

Optimized idea

XOR then count set bits.

Why it works

XOR has a 1 exactly where the numbers differ.

Java implementation

public static int minBitFlips(int start, int goal) {
    return Integer.bitCount(start ^ goal);
}

Explanation

  1. x = start ^ goal
  2. Count set bits of x
  3. Return that count

Problem 203: Check if i-th Bit is Seteasy

Question Statement

True if i-th bit (0-indexed) is set.

Input: n=5, i=0
Output:
true

Brute force

Convert to a binary string and index it.

Optimized idea

Shift right i and check the lowest bit.

Why it works

(n >> i) & 1 isolates bit i.

Java implementation

public static boolean isBitSet(int n, int i) {
    return ((n >> i) & 1) == 1;
}

Explanation

  1. Shift n right by i
  2. AND with 1

A power of two has exactly one set bit.

Problem 209: Count Number of Set Bitseasy

Number of 1 bits.

Input: n=13
Output:
3

Brute force

Check each of 32 bits.

Optimized idea

Brian Kernighan: clear the lowest set bit until zero.

Why it works

The loop runs once per set bit.

Java implementation

public static int countSetBits(int n) {
    int c = 0;
    while (n != 0) { n &= n - 1; c++; }
    return c;
}

[5,3]

Brute force

Use a temporary variable.

XOR swap.

a ^ b ^ b = a and a ^ b ^ a = b.

    a ^= b;

    return new int[]{a, b};

Problem 211: Divide Two Integers Without Operatorsmedium

Question Statement

No *, /, %.

Input: dividend=22, divisor=3
Output:
7

Brute force

Subtract the divisor repeatedly.

Optimized idea

Subtract the largest shifted divisor each time.

Why it works

Doubling the divisor via shifts covers the quotient in binary in O(log^2 n).

Java implementation

public static int divide(int dividend, int divisor) {
    if (dividend == Integer.MIN_VALUE && divisor == -1) return Integer.MAX_VALUE;
    boolean neg = (dividend < 0) ^ (divisor < 0);
    long a = Math.abs((long) dividend), b = Math.abs((long) divisor);
    long q = 0;
    for (int i = 31; i >= 0; i--) {
        if ((b << i) <= a) { a -= b << i; q += 1L << i; }
    }
    return (int) (neg ? -q : q);
}

Explanation

  1. Handle sign and overflow
  2. For i from 31 down while (divisor << i) <= dividend subtract it
  3. Add 1 << i to the quotient

Problem 212: Single Number IIImedium

Question Statement

Two numbers appear once, others twice.

Input: arr=[1,2,1,3,2,5]
Output:
[3,5]

Brute force

Count each element with a map.

Optimized idea

XOR all, split by a set bit.

Why it works

XOR gives a^b; a set bit in it separates a and b into two groups.

Java implementation

public static int[] singleNumberIII(int[] arr) {
    int x = 0;
    for (int v : arr) x ^= v;
    int bit = x & -x, a = 0, b = 0;
    for (int v : arr) { if ((v & bit) != 0) a ^= v; else b ^= v; }
    return new int[]{Math.min(a, b), Math.max(a, b)};
}

Explanation

  1. x = XOR of all
  2. bit = x & -x
  3. XOR numbers with and without the bit separately

Problem 213: Single Number IImedium

Question Statement

Others appear three times.

Input: arr=[2,2,3,2]
Output:
3

Brute force

Count each element with a map.

Optimized idea

Count bit i across all numbers mod 3.

Why it works

Numbers appearing three times contribute multiples of 3 to each bit.

Java implementation

public static int singleNumberII(int[] arr) {
    int res = 0;
    for (int i = 0; i < 32; i++) {
        int s = 0;
        for (int v : arr) s += (v >> i) & 1;
        if (s % 3 != 0) res |= 1 << i;
    }
    return res;
}

Explanation

  1. For each bit 0..31 sum that bit over all numbers
  2. If sum % 3 != 0 set it in the answer

Problem 214: XOR of Numbers from L to Rmedium

Question Statement

XOR of all numbers in [l,r].

Input: l=3, r=5
Output:
2

Brute force

XOR every number from l to r.

Optimized idea

Use the prefix XOR trick f(r) ^ f(l-1).

Why it works

XOR from 1..n follows a pattern repeating every 4.

Java implementation

public static int xorRange(int l, int r) {
    return f(r) ^ f(l - 1);
}

private static int f(int n) {
    switch (n % 4) {
        case 0: return n;
        case 1: return 1;
        case 2: return n + 1;
        default: return 0;
    }
}

Explanation

  1. f(n) by n % 4
  2. Return f(r) ^ f(l-1)

Problem 215: Power Set using Bit Manipulationmedium

Question Statement

All subsets via bitmasks.

Input: arr=[1,2,3]
Output:
8 subsets

Brute force

Recursion with pick / not-pick.

Optimized idea

Iterate masks 0 to 2^n - 1.

Why it works

Each bit of the mask decides whether an element is included.

Java implementation

public static List<List<Integer>> powerSetBits(int[] arr) {
    List<List<Integer>> res = new ArrayList<>();
    int n = arr.length;
    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> s = new ArrayList<>();
        for (int i = 0; i < n; i++) if ((mask & (1 << i)) != 0) s.add(arr[i]);
        res.add(s);
    }
    return res;
}

Explanation

  1. For mask in 0..2^n-1
  2. For each bit set add that element
  3. Add the subset

Problem 216: Count Primes Factors Prime Factorizationmedium

Question Statement

Prime factors of n.

Input: n=12
Output:
[2,2,3]

Brute force

Test every number up to n for primality.

Optimized idea

Trial division up to sqrt(n).

Why it works

After dividing out small factors, any remainder > 1 is prime.

Java implementation

public static List<Integer> primeFactors(int n) {
    List<Integer> r = new ArrayList<>();
    for (int d = 2; (long) d * d <= n; d++)
        while (n % d == 0) { r.add(d); n /= d; }
    if (n > 1) r.add(n);
    return r;
}

Explanation

  1. For d from 2 while d*d <= n
  2. Divide out d
  3. If n > 1 add it
