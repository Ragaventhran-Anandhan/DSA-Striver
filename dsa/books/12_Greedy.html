Problem 277: Assign Cookieseasy

Question Statement

Max content children.

Input: greed=[1,2,3], cookies=[1,1]
Output:
1

Brute force

Try all child-cookie assignments.

Optimized idea

Sort both and match greedily.

Why it works

Giving the smallest sufficient cookie to the least greedy child wastes nothing.

Java implementation

public static int findContentChildren(int[] greed, int[] cookies) {
    Arrays.sort(greed);
    Arrays.sort(cookies);
    int i = 0;
    for (int c : cookies) if (i < greed.length && c >= greed[i]) i++;
    return i;
}

Explanation

  1. Sort greed and cookies
  2. Two pointers
  3. If cookie >= greed assign and move child
  4. Always move cookie

Problem 278: Fractional Knapsackeasy

Question Statement

Max value, items divisible.

Input: val=[60,100,120], wt=[10,20,30], cap=50
Output:
240.0

Brute force

Try all combinations of fractions.

Optimized idea

Sort by value/weight descending and take greedily.

Why it works

The best ratio item always gives the most value per unit.

Java implementation

public static double fractionalKnapsack(int[] val, int[] wt, int cap) {
    int n = val.length;
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) idx[i] = i;
    Arrays.sort(idx, (a, b) -> Double.compare((double) val[b] / wt[b], (double) val[a] / wt[a]));
    double total = 0;
    for (int i : idx) {
        if (cap >= wt[i]) { total += val[i]; cap -= wt[i]; }
        else { total += (double) val[i] * cap / wt[i]; break; }
    }
    return total;
}

Explanation

  1. Sort items by ratio
  2. Take whole items while capacity remains
  3. Take a fraction of the last item

Problem 279: Greedy Algorithm to Find Minimum Number of Coinseasy

Question Statement

Using denominations 1,2,5,10,20,50,100,500,1000.

Input: amount=49
Output:
5

Brute force

DP over all coin counts.

Optimized idea

Greedy with the largest denomination first.

Why it works

For this canonical coin system greedy is optimal.

Java implementation

public static int minCoins(int amount) {
    int[] d = {1000, 500, 100, 50, 20, 10, 5, 2, 1};
    int c = 0;
    for (int x : d) { c += amount / x; amount %= x; }
    return c;
}

Explanation

  1. Denominations in descending order
  2. Use as many of each as possible
  3. Count coins

Problem 280: Lemonade Changeeasy

Question Statement

Give correct change.

Input: bills=[5,5,5,10,20]
Output:
true

Brute force

Try all ways to give change.

Optimized idea

Track the counts of 5s and 10s greedily.

Why it works

Giving the largest bill possible keeps the small bills for later.

Java implementation

public static boolean lemonadeChange(int[] bills) {
    int five = 0, ten = 0;
    for (int b : bills) {
        if (b == 5) five++;
        else if (b == 10) { if (five == 0) return false; five--; ten++; }
        else {
            if (ten > 0 && five > 0) { ten--; five--; }
            else if (five >= 3) five -= 3;
            else return false;
        }
    }
    return true;
}

Explanation

  1. 5: five++
  2. 10: need a 5
  3. 20: prefer 10+5 else 5+5+5

Problem 281: Valid Parenthesis Stringeasy

Question Statement

'*' can be (, ) or empty.

Input: s="(*)"
Output:
true

Brute force

Try every assignment for '*'.

Optimized idea

Track a range [lo, hi] of possible open counts.

Why it works

'*' widens the range; the string is valid if 0 stays in the range at the end.

Java implementation

public static boolean checkValidString(String s) {
    int lo = 0, hi = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') { lo++; hi++; }
        else if (c == ')') { lo--; hi--; }
        else { lo--; hi++; }
        if (hi < 0) return false;
        lo = Math.max(lo, 0);
    }
    return lo == 0;
}

Explanation

  1. '(' increments both
  2. ')' decrements both
  3. '*' lo-- and hi++
  4. If hi < 0 return false
  5. lo is kept >= 0

Problem 282: N Meetings in One Roommedium

Question Statement

Max meetings in one room.

Input: start=[1,3,0,5,8,5], end=[2,4,6,7,9,9]
Output:
4

Brute force

Try all subsets of meetings.

Optimized idea

Sort by end time and pick non-overlapping meetings.

Why it works

Finishing earliest leaves the most time for the rest.

Java implementation

public static int maxMeetings(int[] start, int[] end) {
    int n = start.length;
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) idx[i] = i;
    Arrays.sort(idx, (a, b) -> end[a] - end[b]);
    int count = 0, last = -1;
    for (int i : idx) if (start[i] > last) { count++; last = end[i]; }
    return count;
}

Explanation

  1. Sort meetings by end
  2. Pick if start > last end
  3. Update last end

Problem 283: Jump Game Imedium

Question Statement

Can you reach last index.

Input: arr=[2,3,1,1,4]
Output:
true

Brute force

Try all jump sequences.

Optimized idea

Track the farthest reachable index.

Why it works

If you reach index i, every index below the farthest is reachable.

Java implementation

public static boolean canJump(int[] arr) {
    int reach = 0;
    for (int i = 0; i < arr.length; i++) {
        if (i > reach) return false;
        reach = Math.max(reach, i + arr[i]);
    }
    return true;
}

Explanation

  1. reach = 0
  2. If i > reach return false
  3. reach = max(reach, i + arr[i])

Problem 284: Jump Game IImedium

Question Statement

Min jumps to reach end.

Input: arr=[2,3,1,1,4]
Output:
2

Brute force

BFS or DP over all jumps.

Optimized idea

Greedy with the current range end and farthest reach.

Why it works

Each time the current range is exhausted we need one more jump to the farthest point.

Java implementation

public static int jump(int[] arr) {
    int jumps = 0, end = 0, far = 0;
    for (int i = 0; i < arr.length - 1; i++) {
        far = Math.max(far, i + arr[i]);
        if (i == end) { jumps++; end = far; }
    }
    return jumps;
}

Explanation

  1. jumps = 0, end = 0, far = 0
  2. Update far
  3. When i == end jumps++ and end = far

Problem 285: Minimum Platformsmedium

Question Statement

Min platforms needed.

Input: arr=[900,940,950,1100,1500,1800], dep=[910,1200,1120,1130,1900,2000]
Output:
3

Brute force

Check the overlap count at each time.

Optimized idea

Sort arrivals and departures, two pointers.

Why it works

A platform is needed when the next arrival precedes the earliest departure.

Java implementation

public static int findPlatform(int[] arr, int[] dep) {
    Arrays.sort(arr);
    Arrays.sort(dep);
    int i = 0, j = 0, cur = 0, best = 0;
    while (i < arr.length) {
        if (arr[i] <= dep[j]) { cur++; i++; }
        else { cur--; j++; }
        best = Math.max(best, cur);
    }
    return best;
}

Explanation

  1. Sort both
  2. Move through arrivals
  3. If arr <= dep[j] platforms++ else j++
  4. Track the max

Problem 286: Job Sequencing Problemmedium

Question Statement

Return {jobs, maxProfit}.

Input: deadline=[4,1,1,1], profit=[20,10,40,30]
Output:
[2,60]

Brute force

Try all job subsets and orders.

Optimized idea

Sort by profit descending and place each job in the latest free slot.

Why it works

Placing a high-profit job as late as possible leaves earlier slots for others.

Java implementation

public static int[] jobSequencing(int[] deadline, int[] profit) {
    int n = deadline.length, maxD = 0;
    for (int d : deadline) maxD = Math.max(maxD, d);
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) idx[i] = i;
    Arrays.sort(idx, (a, b) -> profit[b] - profit[a]);
    boolean[] slot = new boolean[maxD + 1];
    int jobs = 0, total = 0;
    for (int i : idx) {
        for (int d = deadline[i]; d >= 1; d--) {
            if (!slot[d]) { slot[d] = true; jobs++; total += profit[i]; break; }
        }
    }
    return new int[]{jobs, total};
}

Explanation

  1. Sort by profit
  2. Find the last free slot <= deadline
  3. Place the job and add its profit

Problem 287: Candymedium

Question Statement

Min candies to children.

Input: ratings=[1,0,2]
Output:
5

Brute force

Try distributions until all rules hold.

Optimized idea

Two passes: left to right and right to left.

Why it works

Each neighbour constraint is satisfied by one of the passes, and max combines them.

Java implementation

public static int candy(int[] ratings) {
    int n = ratings.length;
    int[] c = new int[n];
    Arrays.fill(c, 1);
    for (int i = 1; i < n; i++) if (ratings[i] > ratings[i - 1]) c[i] = c[i - 1] + 1;
    for (int i = n - 2; i >= 0; i--) if (ratings[i] > ratings[i + 1]) c[i] = Math.max(c[i], c[i + 1] + 1);
    int sum = 0;
    for (int x : c) sum += x;
    return sum;
}

Explanation

  1. Everyone starts with 1
  2. Left pass: more rating than left gets left+1
  3. Right pass: more than right gets max(self, right+1)
  4. Sum

Problem 288: Shortest Job Firstmedium

Question Statement

Average waiting time.

Input: burst=[4,3,7,1,2]
Output:
4.0

Brute force

Try all process orders.

Optimized idea

Sort by burst time and accumulate waiting time.

Why it works

Running the shortest jobs first minimizes total waiting.

Java implementation

public static double sjfAvgWaitTime(int[] burst) {
    int[] b = burst.clone();
    Arrays.sort(b);
    long wait = 0, t = 0;
    for (int x : b) { wait += t; t += x; }
    return (double) wait / b.length;
}

Explanation

  1. Sort bursts
  2. wait of job i = sum of earlier bursts
  3. Average = total wait / n

Problem 289: Page Faults in LRUmedium

Question Statement

Count page faults.

Input: pages=[7,0,1,2,0,3,0,4], capacity=3
Output:
6

Brute force

Track recency with a list and linear search.

Optimized idea

LinkedHashSet in access order.

Why it works

The first element is always the least recently used.

Java implementation

public static int pageFaultsLRU(int[] pages, int capacity) {
    LinkedHashSet<Integer> set = new LinkedHashSet<>();
    int faults = 0;
    for (int p : pages) {
        if (set.remove(p)) { set.add(p); continue; }
        faults++;
        if (set.size() == capacity) set.remove(set.iterator().next());
        set.add(p);
    }
    return faults;
}

Explanation

  1. If page is present remove and re-add it
  2. Else count a fault, evict the oldest if full
  3. Add the page

Problem 290: Insert Intervalmedium

Question Statement

Insert and merge.

Input: intervals=[[1,3],[6,9]], newInterval=[2,5]
Output:
[[1,5],[6,9]]

Brute force

Add the interval and re-sort and merge.

Optimized idea

Three-phase linear pass.

Why it works

Intervals before, overlapping and after the new one are handled separately.

Java implementation

public static int[][] insertInterval(int[][] intervals, int[] newInterval) {
    List<int[]> res = new ArrayList<>();
    int i = 0, n = intervals.length;
    while (i < n && intervals[i][1] < newInterval[0]) res.add(intervals[i++]);
    while (i < n && intervals[i][0] <= newInterval[1]) {
        newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
        newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
        i++;
    }
    res.add(newInterval);
    while (i < n) res.add(intervals[i++]);
    return res.toArray(new int[0][]);
}

Explanation

  1. Add intervals ending before newInterval
  2. Merge overlapping intervals into newInterval
  3. Add newInterval and the rest

Problem 291: Non-overlapping Intervalsmedium

Question Statement

Min removals.

Input: intervals=[[1,2],[2,3],[3,4],[1,3]]
Output:
1

Brute force

Try all subsets to remove.

Optimized idea

Sort by end and keep the interval that finishes earliest.

Why it works

This is the same greedy as maximum non-overlapping intervals; removals = total - kept.

Java implementation

public static int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
    int removed = 0, end = Integer.MIN_VALUE;
    for (int[] in : intervals) {
        if (in[0] >= end) end = in[1]; else removed++;
    }
    return removed;
}

Explanation

  1. Sort by end
  2. Keep an interval if start >= last end
  3. Count removed otherwise

Problem 292: Maximum Meetings in One Room (Indices)hard

Question Statement

Indices of meetings.

Input: start=[1,3,0,5,8,5], end=[2,4,6,7,9,9]
Output:
[1,2,4,5]

Brute force

Try all subsets of meetings.

Optimized idea

Sort by end time (ties by index) and pick greedily.

Why it works

Same greedy choice as the count version while recording the indices.

Java implementation

public static List<Integer> maxMeetingsIndices(int[] start, int[] end) {
    int n = start.length;
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) idx[i] = i;
    Arrays.sort(idx, (a, b) -> end[a] != end[b] ? end[a] - end[b] : a - b);
    List<Integer> res = new ArrayList<>();
    int last = -1;
    for (int i : idx) if (start[i] > last) { res.add(i + 1); last = end[i]; }
    return res;
}

Explanation

  1. Sort indices by end
  2. Pick if start > last end
  3. Return 1-based indices
